## 概述

本文档覆盖四个功能组的16个Agent工具。领域模型（辅导工厂模式、OCR管道状态机、记忆持久化模型、家长报告过滤机制）已在设计文档中完整建立，因此跳过 `/grill-with-docs`。工具遵循既有架构模式，跳过 `/plan-eng-review`。整体采用OpenSpec标准工作流：

```
/opsx:explore -> /opsx:propose -> /opsx:apply（TDD全部工具+Evals） -> /code-review -> /opsx:archive -> 合并+打标签
```

| 组别 | 内容 |
|------|------|
| Group A -- 辅导 | 6个专题辅导 + 通用辅导 + 实验模拟 + 方程式配平 |
| Group B -- OCR | 进度查询 + 批量批改 + 结果保存 |
| Group C -- 记忆 | 学生记忆读取 + 教师记忆读取 |
| Group D -- 家长报告 | 报告生成 + 报告发送 |

工具完整定义见 `29-Agent对话系统设计.md` §3.4~§3.7；OCR管道交互序列见 `23-答题卡OCR批改系统设计.md`；记忆模型见 `28-间隔复习与错题强化训练系统设计.md`；评测规范见 `31-评测体系设计.md`。

## OpenSpec工作流

> 工具组遵循标准工作流——领域模型已建立，无需 `/grill-with-docs`；工具遵循既有架构模式，无需 `/plan-eng-review`。

### Step 1: `/opsx:explore`

探索当前Agent架构的代码结构，确认已有工具的实现模式和Evals目录结构。

在Claude Code中输入：

```
/opsx:explore 探索辅导OCR与记忆Agent工具组，设计文档：../4.产品设计/23-答题卡OCR批改系统设计、../4.产品设计/28-间隔复习与错题强化训练系统设计、../4.产品设计/29-Agent对话系统设计
```

### Step 2: `/opsx:propose`

创建辅导、OCR与记忆工具组的OpenSpec变更提案。

在Claude Code中输入：

```
/opsx:propose "实现辅导、OCR与记忆Agent工具组：6个专题辅导+通用辅导+实验模拟+方程式配平、OCR进度查询+批量批改+结果保存、学生记忆+教师记忆读取、家长报告生成+发送"
```

### Step 3: `/opsx:apply`（按tasks.md TDD实现所有工具 + Evals）

按照tasks.md一次性实现16个工具的全部代码和Evals。Claude将从设计文档中自行提取每个工具的规格定义、质量风险和Eval场景，按TDD流程先写测试再实现。

**每个组的设计规格来源**：

| 组别 | 设计文档参考 | 关键验证点 |
|------|------------|-----------|
| Group A: 辅导工厂+6专题 | 30-§3.4 | 工厂函数消除重复；6个专题工具参数覆盖各自化学领域；语言风格约束 |
| Group A: 通用辅导+实验+配平 | 30-§3.4 | 方程式配平规则引擎验证；实验模拟的步骤引导 |
| Group B: OCR | 30-§3.5, 24 | OCR管道状态机；批量批改进度查询；结果持久化 |
| Group C: 记忆 | 30-§3.6, 29 | 跨会话持久化读取；学生/教师视角隔离；间隔复习数据 |
| Group D: 家长报告 | 30-§3.7 | 内容过滤机制；数据权限模型；报告模板 |

在Claude Code中输入：

```
/opsx:apply
```

### Step 4: `/code-review`

实现完成后运行Matt Pocock风格的代码审查，重点关注：工厂函数的代码复用效果、OCR管道状态机的正确性、记忆工具跨会话数据的完整性、家长报告内容过滤的安全性。

在Claude Code中输入：

```
/code-review
```

### Step 5: `/opsx:archive`

归档已完成的辅导、OCR与记忆工具组变更。

在Claude Code中输入：

```
/opsx:archive
```
