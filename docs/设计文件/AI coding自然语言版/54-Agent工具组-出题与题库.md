## 概述

本文档实现Agent系统的第一批工具——出题与题库组。领域模型（出题流程、搜索策略、审核机制、题库管理）已在设计文档中完整建立，因此跳过 `/grill-with-docs`。工具遵循既有架构模式，跳过 `/plan-eng-review`。整体采用OpenSpec标准工作流：

```
/opsx:explore -> /opsx:propose -> /opsx:apply（TDD全部工具+Evals） -> /code-review -> /opsx:archive -> 合并+打标签
```

**本组工具**（详见 `29-Agent对话系统设计` §3.2）：

| 工具 | 功能 | 设计文档参考 |
|------|------|------------|
| 题库搜索 | 多级搜索策略 | 25-§7.4 |
| 联网搜索 | 双路搜索+摘要 | 30-§3.2 |
| 内联出题面板 | _component渲染 | 25-§11.3；30-§五 Guard剥离 |
| 保存到题库 | 持久化+向量同步+_route跳转 | 25-§5.4 |
| LLM出题 | RAG检索->生成->标准化->审核->重试 | 25-§3.1.2、§3.1.3 |
| 题库列表 | 只读查询 | 25-§5.4 |
| 删除题库 | Guard审批门控+级联删除 | 30-§五；25-§5.4 |

## OpenSpec工作流

> 工具组遵循标准工作流——领域模型已建立，无需 `/grill-with-docs`；工具遵循既有架构模式，无需 `/plan-eng-review`。

### Step 1: `/opsx:explore`

探索当前Agent架构的代码结构，确认工具注册表、Evals目录、测试基础设施的状态。

在Claude Code中输入：

```
/opsx:explore 探索出题与题库Agent工具组，设计文档：../4.产品设计/24-AI出题与题库管理系统设计、../4.产品设计/29-Agent对话系统设计
```

### Step 2: `/opsx:propose`

创建出题与题库工具组的OpenSpec变更提案。

在Claude Code中输入：

```
/opsx:propose "实现出题与题库Agent工具组：题库搜索、联网搜索、内联出题面板、保存到题库、LLM出题+审核、题库列表、删除题库"
```

### Step 3: `/opsx:apply`（按tasks.md TDD实现所有工具 + Evals）

按照tasks.md一次性实现7个工具的全部代码和Evals。Claude将从设计文档中自行提取每个工具的规格定义、质量风险和Eval场景，按TDD流程先写测试再实现。

**每个工具的设计规格来源**：

| 工具 | 设计文档参考 | 关键验证点 |
|------|------------|-----------|
| 题库搜索 | 30-§3.2, 25-§7.4 | 多级降级链：本地匹配 -> 向量召回 -> 联网补齐；空关键词/超量limit处理 |
| 联网搜索 | 30-§3.2 | 双路搜索降级：主搜索 -> 备用搜索 -> 两路全故障 |
| 内联出题面板 | 30-§3.2 + §五, 25-§11.3 | _component字段正确生成；参数规范化（string转list）；Guard剥离 |
| 保存到题库 | 25-§5.4 | 创建题集 -> 逐题写入 -> 向量同步；部分失败时最终一致性；_route导航指令 |
| LLM出题 | 25-§3.1.2, 25-§3.1.3 | **核心安全**：审核阻断 -> 重试 -> 上限；变体模式蓝本题注入；化学式标准化 |
| 题库列表 | 25-§5.4 | 只读查询；去重检查（连续两次相同调用） |
| 删除题库 | 30-§五, 25-§5.4 | Guard审批门控拦截；级联删除；向量库清理 |

**LLM出题工具的审核阻断场景**是本组最关键的安全验证点，请务必确认该场景设计充分。

在Claude Code中输入：

```
/opsx:apply
```

在Claude Code中输入：


### Step 5: `/opsx:archive`

归档已完成的出题与题库工具组变更。

在Claude Code中输入：

```

```

## 实现常见问题

| 错误 | 可能原因 | 排查方向 |
|------|---------|---------|
| 搜索失败 | service 导入路径或方法名不匹配 | 检查实际项目中的 import 路径 |
| 联网搜索失败 | API密钥或服务端点配置 | 检查环境变量和网络连通性 |
| 向量库连接失败 | 向量库路径或权限 | 检查向量库路径配置 |
| 工具注册 key 错误 | 注册方式不正确 | 确认使用函数对象而非字符串 |
| LLM出题无限重试 | 重试上限未正确配置 | 检查重试计数器逻辑 |
| 审核阻断场景未触发 | mock的审核结果未正确注入 | 检查mock配置的side_effect |
| 化学式标准化错误 | 正则匹配遗漏特定格式 | 对照设计文档 24-§3.1.3 检查化学式模式 |
