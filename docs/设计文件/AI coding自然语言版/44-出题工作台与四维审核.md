## 技术栈说明

本项目前端不使用 npm 构建流程，静态 HTML 由 FastAPI 直接 serve：

| 技术 | 引入方式 | 用途 |
|------|---------|------|
| Vue 3 | `unpkg.com/vue@3/dist/vue.global.prod.js` CDN | Tab 切换（v-if/v-show）+ 双向绑定 + 列表渲染 |
| Tailwind CSS | `cdn.tailwindcss.com` CDN（`?plugins=forms`） | 原子化样式 |
| KaTeX | `cdn.jsdelivr.net/npm/katex@0.16.11/dist/` CDN | 化学公式/方程渲染 |
| marked | `cdn.jsdelivr.net/npm/marked` CDN | Markdown 题干解析 |
| ECharts | CDN（仅 index.html 用） | 数据图表，本页面不涉及 |

**注意**：不要写 `npm create vite`、`npm install vue-router pinia`、TypeScript 类型定义、Vitest 配置。不要写 Vue SFC（`.vue` 文件）。使用 Vue 3 CDN 的 `Vue.createApp({...})` 模式。前端文件直接在 `frontend/pages/` 下。
