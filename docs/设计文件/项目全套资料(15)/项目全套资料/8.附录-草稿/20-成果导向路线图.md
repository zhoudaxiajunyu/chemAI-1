## 路线图哲学

传统路线图的问题是列出"Q2 上线 OCR 功能"——这告诉团队要做什么，没说为什么。成果导向路线图回答三个问题：
1. **为谁**解决了什么问题？
2. **怎么衡量**问题被解决了？
3. 这个成果与**公司战略**的关系是什么？

## 战略对齐

```
愿景：让每一位化学老师都有一个 AI 助教
  └── 战略主题 A：让老师离不开（效率 + 信任）
  └── 战略主题 B：让学生真正进步（诊断 + 自适应）
  └── 战略主题 C：让家长看得见（透明 + 安心）
```

### 战略主题与北极星指标的关系

北极星指标（详见 `19-OKR目标.md`）是"每月诊断的错题数"。三大战略主题分别驱动北极星指标的不同输入指标：
- 战略主题 A（老师离不开）→ 驱动"上传答题卡数"和"活跃老师数"
- 战略主题 B（学生进步）→ 驱动"诊断采纳率"和"错题诊断覆盖率"
- 战略主题 C（家长看得见）→ 驱动"诊断→报告→续费"的闭环

## Phase 1：种子验证期（当前 — 2026.Q3）

**主题**：证明 3 个核心假设（老师愿意用、诊断可信、全流程闭环）

| # | 成果陈述 | 关键指标 | 如何衡量 |
|---|---------|---------|---------|
| P1-1 | Enable **化学老师** to 在一次考试后 15 分钟内获得全班的错误分类统计报告 so that 讲评准备时间从 6 小时压缩到 1 小时以内 | 单班处理时间 ≤ 15 min | 系统计时器（OCR→报告生成完整链路） |
| P1-2 | Enable **化学老师** to 信任系统的错误诊断分类 so that 讲评方向的决策从"凭经验"变为"有数据支撑" | 诊断与资深老师判断一致率 ≥ 80% | 双盲对照评测 |
| P1-3 | Enable **学生** to 在拿到试卷后知道自己每道错题的"病因"（概念/审题/表达）so that 从"盲目刷题"转为"针对性补救" | 学生端报告查看率 ≥ 60% | 页面访问埋点 |
| P1-4 | Enable **家长** to 每周自动收到一份看得懂的学情简报 so that 家长焦虑从"不知道怎么办"变为"知道该关注什么" | 家长周报打开率 ≥ 50% | 推送→打开追踪 |
| P1-5 | 建立 ChemAI 的可信赖基础——**零安全事故**（不生成危险化学操作、不泄露学生隐私） | 安全事故 = 0 | 审核引擎拦截 + 安全测试 |

**依赖关系**：P1-1（OCR 识别）是 P1-2（诊断）的基础；P1-3 和 P1-4 依赖 P1-2 的输出质量。

## Phase 2：规模化推广期（2026.Q4 — 2027.Q1）

**主题**：从 3 所种子学校扩展到 20 所，验证 B2B2C 模式的可复制性

| # | 成果陈述 | 关键指标 | 如何衡量 |
|---|---------|---------|---------|
| P2-1 | Enable **更多学校的化学教研组** to 在 14 天内从接触到日常使用 so that 增长引擎从"创始人亲自推广"变为"种子老师转介绍" | 新校上线时间 ≤ 14 天 + 转介绍率 ≥ 40% | 新校 onboarding 追踪 |
| P2-2 | Enable **备课组长** to 在跨班对比仪表盘上定位年级共性薄弱知识点 so that 教研活动从"轮流发言"变为"围绕数据讨论" | F7 班级仪表盘周访问率 ≥ 80% | 仪表盘页面埋点 |
| P2-3 | Enable **系统** to 实现 90% 以上的处理不需要人工介入 so that 服务 20 所学校的边际人力成本趋近于零 | 全自动处理占比 ≥ 90% | 人工介入/总处理量 |
| P2-4 | Enable **学生** to 通过自适应练习的"最近发展区"推送实现月度化学成绩的提升 so that 家长愿意为诊断服务付费 | 练习完成率 ≥ 60% + 家长付费转化 ≥ 8% | 练习追踪 + 付费漏斗 |
| P2-5 | Enable **学校管理员** to 将 ChemAI 与学校现有的 LMS（钉钉/企业微信）对接 so that 老师和学生不需要额外记一套账号密码 | LMS 集成率 ≥ 50% 的新签学校 | 集成状态追踪 |

## Phase 3：品类领导者（2027.Q2 — 2027.Q4）

**主题**：让 ChemAI 成为化学教学的基础设施，化学老师"不用就不习惯"

| # | 成果陈述 | 关键指标 | 如何衡量 |
|---|---------|---------|---------|
| P3-1 | Enable **化学老师** to 在日常备课中直接让 AI 生成符合课标要求的练习题 so that 不再依赖教辅书（教辅使用频率下降 50%） | AI 出题采纳率 ≥ 50% | 出题→使用→采纳链路 |
| P3-2 | Enable **区域教育局** to 基于全区学情数据发现教学质量短板学校/知识点 so that 教研资源分配从"平均主义"转为"精准投放" | 教育局合作区域 ≥ 5 个 | 合同签署 |

| P3-4 | Enable **化学学科** to 拥有完整可查询的知识图谱（覆盖 100% 课标知识点）so that ChemAI 成为化学教育领域的"知识基础设施" | 知识点覆盖率 100% + 每知识点 ≥ 20 题 | 知识图谱节点统计 |
| P3-5 | 验证向**物理学科**扩展的可行性 | 物理 MVP 的原型用户验证通过 | 物理老师种子测试 |

## 详细依赖关系与关键路径分析

### Phase 1 内部依赖图

```
P1-5 (零安全事故) ──── 基础性要求，贯穿全阶段 ──── 无前置依赖
         │
P1-1 (OCR 识别) ──── 依赖 F1 OCR 模块 + F3 报告生成
         │           需要 Qwen-VL + Baidu OCR 双引擎调优
         │
         ├──── P1-2 (诊断准确率) ──── 依赖 P1-1 输出质量 + F4 障碍诊断
         │           需要化学学科规则 + LLM 推理的混合模型
         │
         ├──── P1-3 (学生报告) ──── 依赖 P1-2 诊断结果 + F3 学生版报告
         │           需要行为约束 BC-06（鼓励语）+ BC-05（无排名）
         │
         └──── P1-4 (家长周报) ──── 依赖 P1-2 诊断结果 + M16 家长端 + M17 通知
                     需要 BC-09（隐私）+ BC-10（去重）
```

**Phase 1 关键路径**：P1-1（OCR）→ P1-2（诊断）——这是整个 Phase 的瓶颈。OCR 的准确率和速度决定了诊断的素材质量，诊断的准确率决定了所有下游成果的可信度。

**最长路径**：P1-1（OCR ~85%→优化）→ P1-2（诊断 ~80%→优化）→ P1-4（家长端上线）。估算总工期：8-12 周。

### Phase 2 内部依赖图

```
P2-3 (系统全自动 ≥ 90%) ──── 依赖 Phase1 P1-1 + P1-2 的技术成熟度
         │                     需要 AI 出题从 ~65%→补全 + OCR 手写符号识别突破
         │
         ├──── P2-1 (新学校扩展) ──── 依赖 P2-3 的全自动能力（否则人力无法支持 20 校）
         │           需要 M1+M2+M3 用户体系 + M18 LMS 集成 + 销售流程建设
         │
         ├──── P2-2 (仪表盘使用) ──── 依赖 Phase1 P1-2 的诊断数据积累
         │           需要学情面板 → 补全跨班对比功能
         │
         ├──── P2-4 (学生练习+付费) ──── 依赖 Phase1 P1-3 的学生端活跃
         │           需要自适应引擎 + M12 间隔复习
         │
         └──── P2-5 (LMS 集成) ──── 依赖 M18 4 连接器
                     需要钉钉/企业微信/LTI 1.3 的接口对接和测试
```

**Phase 2 关键路径**：P2-3（全自动）→ P2-1（学校扩展）→ P2-4（付费转化）。全自动化是规模化的前提；没有规模化就没有足够基数支撑付费转化。

**最长路径**：P2-3（技术攻坚 8-12 周）→ P2-1（销售周期 8-16 周）→ P2-4（转化孵化 4-8 周）。估算总工期：20-36 周（跨两个季度合理）。

### Phase 3 内部依赖图

```
P3-4 (知识图谱 100%) ──── 依赖 Phase2 的数据积累（多校多班的题目数据）
         │                  需要 M22 知识图谱 + ChromaDB + PubChem
         │
         ├──── P3-1 (AI 出题采纳) ──── 依赖 P3-4 知识图谱覆盖 + Phase2 P2-3 的成熟度
         │
         ├──── P3-3 (间隔复习优化) ──── 依赖 Phase2 P2-4 的学生练习数据 + M12 系统
         │
         └──── P3-2 (教育局合作) ──── 依赖 Phase2 P2-1+P2-2 的学校密度
         │                  需要 M13 预警 + 仪表盘 + M24 导出服务
         │
P3-5 (物理扩展) ──── 相对独立，但需要 Phase1-2 验证"诊断模型可跨学科迁移"
```
**Phase 3 关键路径**：P3-4（知识图谱完整）→ P3-1（AI 出题采纳）→ P3-2（教育局合作）。知识图谱是 AI 出题的内容基础，AI 出题的采纳率是向教育局证明"技术实力"的证据。

## 替代情景分析：乐观/基准/悲观时间线

### Phase 1-3 的三种情景

| 里程碑 | 乐观情景（Best Case） | 基准情景（Base Case） | 悲观情景（Worst Case） |
|--------|-------------------|-------------------|---------------------|

| **20 所学校覆盖** | 2027.Q1 末 | 2027.Q2 中期 | 2027.Q4 |
| **全自动处理 ≥ 90%** | 2027.Q1 末 | 2027.Q2 中期 | 2027.Q4 |
| **家长端付费转化 ≥ 8%** | 2027.Q2 | 2027.Q3 | 2028.Q1 |
| **教育局首个合同** | 2027.Q2 | 2027.Q3 | 2028.Q1 |
| **50+ 所学校覆盖** | 2027.Q3 | 2027.Q4 | 2028.Q4 |
| **知识图谱完整（100%）** | 2027.Q3 | 2027.Q4 | 2028.Q2 |
| **物理学科验证** | 2027.Q4 | 2028.Q1 | 2028.Q4（或放弃扩展） |

### 乐观情景的前提条件

1. **技术**：OCR 手写符号识别在 Qwen-VL 新版本中取得突破性进展
2. **市场**：种子校口碑传播速度快——第一个月内 ≥ 2 位种子老师主动带来新学校
3. **团队**：能在 Q4 初招聘到满足需求的全栈工程师
4. **政策**：2026 年下半年教育部出台支持 AI 教学工具的正面政策

### 悲观情景的核心障碍

1. **技术**：手写化学符号 OCR 识别率卡在 85%，无法突破到 90%+
2. **市场**：学校预算收紧（地方财政压力传导），信息化采购优先级下降
3. **竞争**：讯飞在 2027 年上半年推出"化学精品分析"功能模块
4. **人才**：难以在小城市招聘到合适的全栈工程师

### 情景规划的行动原则

- **2026.Q3**：关注 OCR 识别的实际表现（乐观/悲观的分水岭）
- **2026.Q4**：关注种子校续约/付费意愿（决定是否需要 pivot）
- **2027.Q1**：关注新学校扩展速度（决定加大投入还是保守运营）
- **如果连续 2 个季度处于悲观情景**：考虑战略 pivot——从"独立产品"转向"嵌入科大讯飞/学科网等平台的化学诊断模块"

## Go / No-Go 决策门

在 Phase 之间设置明确的 go/no-go 决策门，确保资源只投入到已验证的方向。

### Gate 1：Phase 1 → Phase 2（种子验证 → 规模化推广）

**决策时间**：2026.Q4 初（Phase 1 结束后）

**Go 条件（必须同时满足）**：
1. 种子老师周活跃率 ≥ 80%（连续 ≥ 4 周）
2. 诊断与资深教师一致率 ≥ 60%（Launch Blocker 标准），且趋势向上
3. OCR 处理 P95 ≤ 15 分钟（连续 ≥ 10 次处理）
4. 安全事故数 = 0
5. ≥ 2/3 种子学校表达了续约/付费意向

**No-Go 触发条件（满足任意一条即暂停）**：
1. 种子老师周活跃率 < 50%
2. 发生任何一次方程式配平错误（零误差红线被突破且无法快速修复）
3. 连续 3 个种子老师主动停止使用（非技术原因）
4. 诊断一致率 < 50%（教师普遍不信任系统）

**No-Go 后的行动**：
- 如果 No-Go 由技术原因触发：Phase 1 延期 1 个季度，聚焦技术攻坚
- 如果 No-Go 由市场原因触发：启动 pivot 评估

**Gate 1 决策模板**：

```
═══════════════════════════════════════════
Gate 1 决策记录 — [日期]
═══════════════════════════════════════════

【Go 条件达成情况】
1. 周活跃率: [X%] → □达标 □未达标
2. 诊断一致率: [X%] → □达标 □未达标
3. OCR P95: [X 分钟] → □达标 □未达标
4. 安全事故: [X 次] → □达标 □未达标
5. 付费意向: [X/3 学校] → □达标 □未达标

【决策】□ GO — 进入 Phase 2  □ NO-GO — [原因]
【决策人】创始人
【下一步行动】[GO/NO-GO后的具体计划]
═══════════════════════════════════════════
```

### Gate 2：Phase 2 → Phase 3（规模化 → 品类领导者）

**决策时间**：2027.Q2 初（Phase 2 结束后）

**Go 条件（必须同时满足）**：
1. 覆盖学校 ≥ 15 所（接近 20 所目标）
2. 学校续约率 ≥ 70%（已到续约周期的学校）
3. 全自动处理占比 ≥ 85%
4. LTV/CAC ≥ 2.5:1
5. 不同类型学校（重点/普通/县级）的核心指标差异 ≤ 20%

**No-Go 触发条件（满足任意一条即暂停）**：
1. 覆盖学校 ≤ 8 所（规模无法支撑 Phase 3 的投资）
2. 学校续约率 < 50%（产品-市场匹配不成立）
3. 竞争环境剧变（如科大讯飞推出免费竞品）

**No-Go 后的行动**：评估是"速度问题"还是"方向问题"——速度问题延期，方向问题 pivot。

### Gate 3：Phase 3 → 物理学科扩展

**决策时间**：2027.Q4 初

**Go 条件**：
1. 化学学科学校覆盖 ≥ 40 所（足够的用户基础）
2. 化学学科月度现金流为正（可持续的商业模式）
3. 物理 MVP 原型 ≥ 2/3 物理种子老师"愿意试用完整版"
4. 物理学科诊断模型的核心差异已识别，且有明确的开发路径

**No-Go 条件**：物理 MVP 原型种子测试失败 → 放弃物理扩展，聚焦化学深耕。
