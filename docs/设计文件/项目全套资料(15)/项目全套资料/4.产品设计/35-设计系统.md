# 35. 设计系统

> 产品设计文档 | ChemAI 智辅化学 | 设计阶段

## 一、设计理念：Academic Catalyst（学术催化剂）

ChemAI 设计系统的核心隐喻：**ChemAI 是化学学习的催化剂**——降低学习反应的活化能，自身不消耗。

这个隐喻拆解为三根支柱，每根支柱对应一组设计决策：

**支柱一：学术严谨。** ChemAI 是给学校用的教学工具，不是娱乐 App。视觉上需要传达专业感和可信赖感。Oxford Blue（牛津蓝）作为主色调——沉静、权威、不轻浮。教师看到这个界面，第一反应应该是"这是一款严肃的教学产品"。

**支柱二：现代学术。** 界面采用冷调主背景（#f7f9fc）+ 白色表面 + 浅灰层次（#f1f5f9），营造现代、干净、专业的学术氛围。信息层级靠明度差表达，不依赖纹理装饰。

**支柱三：清晰分层。** AI 对话气泡用青色调（Teal），区别于系统 UI 的牛津蓝——暗示"这是 AI 在和你对话，不是系统在命令你"。语义状态（通过/警告/阻断）以浅底深字的标签式呈现，一眼可辨且不喧宾夺主。

三条设计原则：
- **学术但不冰冷**：牛津蓝 + 冷调现代背景，专业而不疏远
- **现代但不炫技**：信息层级靠明度与留白表达，不堆砌装饰
- **化学但不炫技**：化学式渲染（KaTeX）、元素符号等化学元素用于功能场景，不干扰内容可读性

## 二、技术实现方式

ChemAI 设计系统通过以下技术组合落地。技术选型的完整论证见 [37-技术选型与工具链](./37-技术选型与工具链.md)。

| 技术 | 在设计系统中的角色 |
|------|-------------------|
| React 19 | 教师端组件化 SPA，页面交互逻辑与状态管理 |
| Vite | 开发构建，多页面输出 |
| Tailwind CSS | 原子化样式系统，色彩/间距/排版通过预定义类名控制，保证视觉一致性 |
| antd 组件库 | 基础组件（表格、抽屉、弹窗、表单）与主题令牌统一 |
| KaTeX + mhchem | 化学方程式和数学公式的正确渲染 |
| ECharts | 学情面板图表渲染（KPI、趋势、分布、热力图） |

学生端/家长端为移动优先的轻量页面，遵循同一色彩与组件规范。

核心原则：**设计令牌统一**——颜色/字体/间距通过设计令牌（Tailwind 类名 + antd 主题）集中定义，化学式渲染统一走 KaTeX，保证跨页面视觉一致性。

## 三、色彩系统

### 3.1 设计思路

ChemAI 的色彩系统用三层结构组织：**主色（定义产品气质）→ 语义色（传达信息状态）→ 装饰色（营造化学氛围）**。每一层有明确的用途边界，不混用。

### 3.2 主色层

三种主色定义了 ChemAI 的视觉气质：

| 色彩 | 色值 | 气质 | 用途 |
|------|------|------|------|
| Oxford Blue（牛津蓝） | `#002147` | 沉静、权威、学术 | 主按钮、侧边栏、标题强调 |
| Teal（学术青） | `#0d7377` | 现代、对话感、智能 | AI 对话气泡、辅助按钮、化学元素强调 |
| 冷调主背景 | `#f7f9fc` | 现代、干净、专业 | 页面主背景 |

设计要点：Oxford Blue 是"系统的声音"（导航、按钮、标题），Teal 是"AI 的声音"（对话气泡、智能建议），冷调主背景是"纸的声音"（页面底色）。三者各司其职，学生和教师通过颜色就能判断信息来源。

### 3.3 完整色板

| 色板变量 | 色值 | 用途 |
|---------|------|------|
| 正文色 | `#0f172a` | 所有正文文字 |
| 主背景 | `#f7f9fc` | 页面底色（冷调） |
| 表面色 | `#ffffff` | 卡片、弹窗底色 |
| 浅灰面 | `#f1f5f9` | 侧边栏、分区底色 |
| 次要文字 | `#475569` | 辅助说明、时间戳、标签 |
| 弱化文字 | `#94a3b8` | 占位符、禁用态 |
| 边框 | `#e2e8f0` | 卡片边框、分割线 |
| 主色悬停 | `#001a38` | 牛津蓝按钮的悬停加深 |
| 青色悬停 | `#0a5c5f` | 学术青按钮的悬停加深 |
| 错误红 | `#b43c28` | 审核阻断、错误提示、删除操作 |
| 通过绿 | `#2c6e49` | 审核通过、正确标记、成功提示 |
| 链接蓝 | `#2563eb` | 超链接、次要强调 |

### 3.4 语义色：状态传达

三种状态色用于传达操作结果，采用"浅色背景 + 深色文字"的标签式呈现（而非纯色填充按钮），降低视觉噪音：

| 状态 | 背景 | 文字 | 场景 |
|------|------|------|------|
| 通过 | 极浅绿 | 深绿 | 题目审核通过、答案正确 |
| 警告 | 极浅黄 | 深棕 | 审核警告、需人工复核 |
| 阻断 | 极浅红 | 深红 | 审核阻断、安全问题 |

### 3.5 辅助色：结构辅助

辅助色用于表达界面结构与交互状态，不参与语义传达：

| 色板变量 | 色值 | 用途 |
|---------|------|------|
| 边框 | `#e2e8f0` | 卡片边框、表格分割线 |
| 强边框 | `#cbd5e1` | 输入框聚焦、强调分割 |
| 浅灰面 | `#f1f5f9` | 悬停底色、分区背景 |

## 四、视觉主题：方向 A · 现代学术蓝

现代学术蓝是当前应用的视觉主题。它在保留品牌基因（牛津蓝主色、学术青 AI 色、语义色）的前提下，将界面从纸感模拟调整为冷调现代风格，核心手法：

**冷调主背景**：主背景 #f7f9fc、表面 #ffffff、浅灰面 #f1f5f9，信息层级靠明度差而非纹理表达。

**系统字体栈**：中文正文使用系统字体（PingFang SC / Microsoft YaHei / Noto Sans SC），本地无 Google Fonts 依赖，加载更快、渲染一致。

**圆角体系**：8 / 12 / 16 / 9999 四档圆角——按钮 8px、卡片 12px、弹窗 16px、标签胶囊 9999px。

**柔和阴影**：三级阴影（1px / 4px / 12px 模糊半径），层级分明不喧宾夺主。

**语义色标签**：通过/警告/阻断以浅底深字标签呈现（通过 #e7f2ec/#2c6e49、警告 #fdf3e3/#b45309、阻断 #fbeae7/#b43c28）。

## 五、字体系统

字体选择的核心逻辑：**化学式需要等宽字体的精确对齐，正文需要阅读舒适的无衬线字体，标题需要传达学术感。**

| 用途 | 字体选择 | 理由 |
|------|---------|------|
| 标题 | 系统无衬线加粗（PingFang SC / Microsoft YaHei） | 清晰、现代，与整体冷调风格一致 |
| 正文 | 系统字体栈（PingFang SC / Microsoft YaHei / Noto Sans SC） | 本地字体无加载依赖，跨平台渲染一致 |
| 化学式、代码、数据 | JetBrains Mono | 等宽字体保证上下标对齐，化学方程式中的数字和符号不偏移 |

化学式渲染对等宽字体的要求很高——H₂SO₄ 中的下标 `₂` 和 `₄` 必须与字母等宽对齐，否则方程式看起来参差不齐。JetBrains Mono 是为代码设计的等宽字体，天然满足这个需求。

## 六、化学式渲染

化学式的正确显示是 ChemAI 的用户体验底线——一个配平正确但显示错误的方程式，教师不会信任这个产品。

ChemAI 的化学式渲染分两条路径：

**路径一：API 数据中的化学式。** 后端返回的 JSON 数据中如果包含化学式文本（如题目正文、答案解析），系统自动将纯文本格式（如 H2O、SO4^2-）转换为带上下标格式的化学式（H₂O、SO₄²⁻）。这个转换在后端响应阶段完成，前端收到的已经是格式化后的内容。

**路径二：用户可见的化学式。** 前端通过 KaTeX + mhchem 扩展渲染化学方程式。mhchem 是 LaTeX 的化学宏包，支持化学式上下标、化合价、反应箭头、配平系数等全部化学排版需求。用户输入 `\ce{CH4 + 2O2 -> CO2 + 2H2O}`，渲染结果就是化学课本上看到的标准方程式格式。

| 输入语法 | 渲染效果 | 场景 |
|---------|---------|------|
| `\ce{H2O}` | H₂O | 分子式 |
| `\ce{SO4^2-}` | SO₄²⁻ | 离子式 |
| `\ce{Fe^3+ + e- -> Fe^2+}` | Fe³⁺ + e⁻ → Fe²⁺ | 半反应方程式 |
| `\ce{CH4 + 2O2 -> CO2 + 2H2O}` | CH₄ + 2O₂ → CO₂ + 2H₂O | 完整化学方程式 |

## 七、组件设计

以下是 ChemAI 设计系统中的核心 UI 组件及其设计意图。具体样式规格（尺寸、间距、圆角）在开发阶段通过 Tailwind CSS 类名统一控制，本文档只描述组件的用途、变体和交互行为。

### 7.1 按钮

六种按钮变体，按视觉权重从高到低排列：

| 变体 | 视觉特征 | 使用场景 |
|------|---------|---------|
| 主按钮 | Oxford Blue 实心填充，白色文字 | 页面最重要的操作：提交、生成、保存 |
| 次按钮 | Oxford Blue 描边，透明背景 | 次要操作：取消、返回、暂存 |
| AI 按钮 | Teal 实心填充，白色文字 | AI 相关操作：智能出题、AI 诊断 |
| 渐变按钮 | 铜蓝→靛蓝→甲基绿的渐变填充 | 化学相关的重要操作：开始批改、启动实验模拟 |
| 小按钮 | 主按钮的缩小版 | 表格行内操作、卡片内联操作 |
| 图标按钮 | 纯图标，无文字 | 关闭、刷新、设置等工具栏操作 |

按钮的共同特征：圆角 8px（亲和但不过于圆润），悬停时颜色加深 + 轻微上浮阴影，点击时有缩小的按压反馈。

### 7.2 卡片

三种卡片变体对应三种信息密度和氛围：

- **标准卡片**：白色表面、浅灰边框、悬停时轻微阴影。用于信息列表、数据展示等常规场景。
- **强调卡片**：顶部 4px 蓝色装饰条。用于需要从卡片列表中突出的信息（如当前进行中的考试）。
- **语义强调卡片**：浅底深字 + 左侧强调边距线。用于传达状态语义的卡片（通过/警告/阻断）。

### 7.3 标签

标签用于快速传达分类信息，采用"浅色背景 + 深色文字"的轻量视觉：

- **难度标签**：简单（青色）、中等（蓝色）、困难（红色）——遵循"绿→蓝→红"的难度递进隐喻
- **障碍类型标签**：概念理解型（紫色）、审题障碍型（蓝色）、表述障碍型（青色）——三种颜色无等级关系，平行区分

### 7.4 审核标记

每道 AI 生成的题目经过四维安全审核后，在题目卡片上展示审核标记。标记分三种状态：

- **全部通过**：绿色底，四个维度均显示 ✓，表示题目可安全下发
- **部分警告**：黄色底，对应维度显示 ⚠，表示题目可用但建议人工复核
- **阻断**：红色底，对应维度显示 ✗，表示题目不可用——该题目不会出现在学生端

### 7.5 弹窗

弹窗用于确认操作或展示详细信息，由三层叠加构成：半透明遮罩层（阻断背景操作）→ 白色卡片（展示内容）→ 底部按钮区（确认/取消，右对齐）。大内容弹窗（如学情报告预览）增加可滚动区域。

### 7.6 通知提示

操作反馈采用右上角浮出的轻量提示，3 秒后自动消失。Oxford Blue 底色配白色文字。与弹窗的区别：通知不阻断用户操作，不需要用户点击确认。

### 7.7 输入框

两种风格：

- **标准输入框**：浅灰边框、圆角 8px，聚焦时边框变为蓝色并出现淡蓝色光晕。用于表单、搜索等常规输入。
- **极简输入框**：无边框、仅底部 2px 灰色实线、透明背景。聚焦时底部线变为蓝色。用于对话输入、内联编辑等"轻量"场景。

### 7.8 状态占位

三种全局状态的设计意图：

- **空状态**：半透明烧杯图标 + 灰色引导文字。不冷冰冰地显示"暂无数据"，而是告诉用户"你可以做什么"（如"请先创建一次考试"）
- **加载状态**：三点依次弹跳的动画。表示系统正在处理中，不是卡死了
- **错误状态**：红色错误描述 + 重试按钮。告诉用户发生了什么 + 给出下一步行动

## 八、响应式策略

ChemAI 面向三种使用场景，设计系统对不同屏幕采用不同的布局策略：

| 场景 | 典型设备 | 布局策略 |
|------|---------|---------|
| 教师端 | 桌面（≥1024px） | 三栏：侧边导航 + 主内容区 + AI 对话面板。信息密度高，适合数据查看和多任务操作 |
| 教师端（小屏） | 平板（768-1023px） | 两栏：折叠侧边栏（仅图标） + 主内容区。AI 对话面板隐藏，通过按钮呼出 |
| 学生端/家长端 | 手机（<768px） | 单栏：顶部标题栏 + 内容区 + 底部三 Tab 导航。大触控区域，卡片式内容，接近原生 App 体验 |

学生端和教师端采用不同的设计语言：
- 教师端：数据密集、表格为主、专业工具感。侧边栏深色系，视觉重心在"效率"
- 学生端：卡片式、大触控区、引导式交互。浅色背景为主，视觉重心在"内容理解"

桌面端可切换至手机视口预览学生端效果，无需启动移动设备。

**明确断点与视口规格**（统一口径，与 38/41 号文档一致）：

| 参数 | 值 | 说明 |
|------|-----|------|
| 移动端视口 | **430×900** | 学生端/家长端设计视口（38 号第四二节、41 号原型相同口径；QA 按此视口验收） |
| 移动端内容容器 | max-width 390px、min-height 844px、margin 0 auto | 手机壳居中容器（41 号原型实现），背景色加深模拟手机边框 |
| 断点 | <768px（手机）/ 768-1023px（平板）/ ≥1024px（桌面） | 上表场景的精确边界；教师端桌面 ≥1280px 为推荐宽度 |
| 化学式/代码字体 | JetBrains Mono | 与 §五 字体系统一致 |
