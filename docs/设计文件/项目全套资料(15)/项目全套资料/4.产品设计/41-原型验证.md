## 本阶段目标

前面 19-38 号文档已经完成了信息架构、页面流程、设计系统的全部设计工作。这一步的目标是**用视觉原型验证设计**：

1. **读设计文档**：从 20-信息架构的组件表和 35-设计系统中提取关键信息
2. **写 Stitch 提示词**：把组件清单翻译成 Stitch 能理解的英文提示词

4. **对照验证**：回到设计文档的组件表，逐项核对生成结果

本质上是用可交互的 HTML 原型来"试跑"静态设计文档，在设计阶段发现遗漏或矛盾，而非到编码阶段才发现。

- **产出**：14 个 HTML 页面原型，每个对照设计文档组件表验证通过

## 开发流程

整个原型设计分为 14 个 Step，每个页面对应一个 Step。每个 Step 遵循统一的结构：**读设计 -> 写 Stitch 提示词 -> 生成原型 -> 对照验证 -> 提交**。

### Step 的通用结构

```
Step N: [页面名称]

读设计 → 打开 设计文档 §X 组件表，列出该页面包含哪些组件
写 Stitch 提示词 → 让 Claude Code 把组件清单翻译成一段英文提示词
生成原型 → 把提示词粘贴到 Stitch，得到 HTML，导出文件
对照验证 → 回到 设计文档 §X 组件表，逐项核查，缺失项修改提示词重新生成
归档 → 将生成的 HTML 文件保存到对应目录，记录提示词用于后续复现
```

### 写 Stitch 提示词的方法

这一段很重要，因为它贯穿全部 14 个 Step。你需要理解每一条出现在提示词里的信息是从设计文档 的哪个位置提取出来的。

> **注意**：各 Step 提示词示例中的色值与字体均以 [35-设计系统](./35-设计系统.md) 为准——Oxford Blue `#002147`、Teal `#0d7377`、冷调主背景 `#f7f9fc`、系统字体栈（PingFang SC / Microsoft YaHei）+ JetBrains Mono、侧边栏 232px。

**Stitch 提示词 = 组件清单 + 设计约束 + 布局描述**

一个标准的 Stitch 提示词由以下信息拼装而成：

| 提示词要素 | 从哪里提取 | 示例 |
|-----------|-----------|------|
| 视口尺寸 | 设计文档指定的端型 | "Desktop 1280px+" 或 "Mobile 430x900" |
| 布局结构 | 设计文档 §5 组件表的 DOM 结构列 | "Left sidebar 232px + right chat area, using flexbox" |
| 组件列表 | 设计文档 §5 组件表中列出的全部组件 | 每个组件名称 + 它在页面上的位置 |
| 颜色 | 35-设计系统 §3 色彩系统 | "Oxford Blue #002147 for primary buttons, Teal #0d7377 for AI bubbles" |
| 字体 | 35-设计系统 §5 字体系统 | "Titles: bold sans-serif, Body: PingFang SC / Microsoft YaHei" |
| 圆角/间距 | 35-设计系统 §7 组件库 | "8px border-radius for cards, 12px for chat bubbles" |
| 静态数据 | 各页面需要的示例内容 | "Show 3 sample chat messages", "Show 4 KPI cards with mock numbers" |

你不需要手动写提示词。每个 Step 中，你会**先让 Claude Code 帮你生成提示词**，然后把 Claude Code 的输出粘贴到 Stitch 中。Claude Code 充当"翻译"——它把你用中文描述的组件清单转成 Stitch 能理解的结构化英文指令。

具体流程：

1. 你在 Claude Code 中输入一段中文指令，描述该页面包含哪些组件（从 设计文档 §5 的组件表中照抄）
2. Claude Code 生成一段可以直接粘贴到 Stitch 的英文提示词
3. 你打开 stitch.google.com，粘贴进去，点击生成
4. Stitch 生成 HTML 后，你导出文件，回到 设计文档 §5 组件表逐项核对

**提示词要写多长**：每个页面的提示词长度取决于其复杂度。index.html 约 300-500 英文单词，m/login.html 约 200 英文单词。不要追求"写得很全面"——Stitch 的处理能力有限，一次描述 6-8 个核心组件效果最好。如果一个页面组件太多（如 exam-v2.html 有 4 个 Tab），分多次生成，每次生成一部分。

**提示词使用的关键技巧**：

- 颜色写色值不写名称。Stitch 不理解 "Oxford Blue"，只识别 `#002147`。
- 布局写明确。说 "flexbox horizontal layout, left column 232px fixed, right column fills remaining space"，不说 "two-column layout"。
- 尺寸写具体 px 值。说 "height 56px, 8px border-radius"，不说 "a nice looking button"。
- 交互写明触发方式和效果。说 "clicking 'Details' button adds a CSS class that slides the drawer from right", 不说 "drawer opens"。
