# 38. 前端页面设计规格

> 本文档是 ChemAI 全部 14 个前端页面的集中设计规格。每个页面包含布局结构、组件清单、状态处理和交互行为四部分。视觉语言（颜色/字体/间距/组件样式）详见 [35-设计系统](./35-设计系统.md)。

---

## 一、教师端（6 个页面）

### 1.1 AI Agent 对话主面板

**页面概述**：教师端入口页面。左侧固定导航栏 + 中央对话区，教师通过自然语言对话完成出题、批改、诊断等全部操作。

**布局分区**：

| 分区 | 位置 | 说明 |
|------|------|------|
| 侧边栏 | 左侧固定 232px | 品牌标识、新建对话按钮、历史会话列表、底部快捷导航图标 |
| 对话区 | 中央自适应 | AI 气泡（Teal 浅色背景，左对齐，圆角）与用户气泡（白底灰边框，右对齐）交替排列 |
| 上下文标签 | 对话区顶部 | 显示当前选中的班级/考试/学生，点击可切换或清除 |
| 快捷芯片 | 输入区上方 | 6 个预设提示语按钮，横向排列 |
| 化学式输入栏 | 输入区上方 | 常用化学符号和方程式的快捷输入按钮组 |
| 输入区 | 页面底部固定 | 多行文本输入框 + 文件上传按钮 + 发送按钮 |
| Agent 状态栏 | 输入区上方 | 实时显示 Agent 当前阶段和工具执行计时器 |

**组件清单**：

| 组件 | 状态变体 | 数据来源 |
|------|---------|---------|
| 侧边栏 | 默认展开、折叠（仅图标） | 会话列表 API + 客户端本地缓存 |
| 对话气泡 | AI 气泡（Teal 背景）、用户气泡（白底灰框） | Agent SSE 流式对话 |
| 上下文标签 | 有选中项（显示标签）、无选中项（隐藏） | 客户端会话存储 |
| 快捷芯片 | 默认（6 个按钮）、发送后隐藏 | 静态配置 |
| 化学式输入栏 | 始终可见 | 客户端渲染 |
| 输入框 | 默认（placeholder）、输入中（文字计数）、发送中（禁用） | 用户输入 |
| 文件上传按钮 | 默认、拖拽悬停（高亮）、上传中（进度条） | 用户操作 |
| Agent 状态栏 | 分析中（浅蓝背景）、执行中（浅蓝 + 计时器）、等待审批（浅黄）、错误（浅红） | SSE phase 事件 |

**关键交互**：
- 发送消息后，输入框清空并禁用，快捷芯片隐藏，Agent 状态栏显示"分析中"
- 工具调用期间，工具调用卡片出现在对话流中，带实时计时器
- 审批类工具触发时，对话流中出现确认/取消卡片（黄色边框、米黄背景）
- 侧边栏历史列表顶部为最新对话，点击切换，长按删除

**状态处理**：

| 状态 | 设计 |
|------|------|
| 加载态 | 侧边栏显示骨架屏（灰色占位条），对话区显示"正在连接..." |
| 空态 | 无历史对话时，对话区显示欢迎语 + 6 个快捷芯片 + 输入框 |
| 错误态 | SSE 连接断开时，显示"连接中断，点击重试"横幅，发送按钮变为重试按钮 |

### 1.2 考试工作台

**页面概述**：教师出题和题库管理的核心页面。4 个 Tab 切换，支持 AI 生成、手动录入、OCR 导入三种出题模式。

**布局分区**：

| 分区 | 说明 |
|------|------|
| Tab 导航栏 | 顶部 4 个 Tab（出题工作台 / 题库管理 / 历史真题库 / 考试列表），当前激活 Tab 有下划线指示 |
| Tab 内容区 | 根据激活 Tab 切换显示对应内容 |

**组件清单（Tab 1：出题工作台）**：

| 组件 | 状态变体 | 数据来源 |
|------|---------|---------|
| 子模式切换 | AI 生成（默认）、手动录入、OCR 导入 | 客户端切换 |
| 题型选择器 | 多选 chip（选择题/填空题/计算题/实验题/推断题） | 静态配置 |
| 难度选择 | 下拉单选（easy/medium/hard/competition） | 静态配置 |
| 知识点搜索 | 可搜索多选 chip 输入框 | 知识点列表 API |
| 变体模式开关 | 复选框 + 蓝本题选择 | 历史真题 API |
| 目标题库选择 | 下拉选择已有文件夹或新建 | 题库列表 API |
| 生成按钮 | 默认、生成中（loading + 禁用） | — |
| 题目卡片列表 | 每张卡片含题目内容、审核徽章（passed=绿/warning=黄/blocked=红）、RAG 来源标识、陷阱提示、操作按钮（编辑/删除/加入考试/加入题库） | 题目生成 API |

**组件清单（Tab 2：题库管理）**：

| 组件 | 数据来源 |
|------|---------|
| 左侧文件夹列表 | 题库文件夹 API |
| 右侧题目卡片网格 | 文件夹详情 API |
| 批量操作栏 | — |

**组件清单（Tab 3：历史真题库）**：

| 组件 | 数据来源 |
|------|---------|
| 地区/年份树形浏览器 | 试卷列表 API |
| 关键词搜索框 | 历史真题搜索 API |
| 真题卡片列表 | 搜索/浏览结果 |
| 选题操作（加入考试/设为蓝本） | — |

**组件清单（Tab 4：考试列表）**：

| 组件 | 数据来源 |
|------|---------|
| 创建考试按钮 | — |
| 考试卡片列表（含状态标签：草稿/已发布/进行中/已完成） | 考试列表 API |
| 操作菜单（编辑/发布/导出/删除） | — |

**关键交互**：
- Tab 切换通过组件状态控制（SPA 内为 Tab 组件切换，移动端轻量页面为显隐切换）
- 题目生成完成后，题目卡片从上方插入，带入场动画
- 审核徽章 passed=绿色背景+深青文字，warning=黄色背景+深棕文字，blocked=红色背景+深红文字

**状态处理**：

| 状态 | 设计 |
|------|------|
| 加载态 | 题库列表显示骨架屏，题目网格显示占位卡片 |
| 空态 | 题库为空时显示"暂无题目，点击上方开始出题" |
| 错误态 | 生成失败时，生成按钮恢复可用 + Toast 显示错误原因 |

### 1.3 班级学情面板

**页面概述**：教师查看班级学习数据的仪表盘。包含 4 个 KPI 概要卡片、3 个图表和重点关注学生列表。

**布局分区**：

| 分区 | 说明 |
|------|------|
| 工具栏 | 顶部：班级下拉选择器 + 时间范围选择器 |
| KPI 卡片区 | 4 列网格：考试次数、需关注学生、班级人数、最近均分 |
| 图表区 | 2 列网格（知识点错误率柱状图 + 障碍类型分布图）+ 全宽成绩趋势折线图 |
| 关注学生区 | 条件渲染，横向可滚动横条，展示 Top 5 需关注学生 |

**组件清单**：

| 组件 | 状态变体 | 数据来源 |
|------|---------|---------|
| 班级选择器 | 默认（第一个班级）、切换后重新加载面板 | 班级列表 API |
| KPI 卡片 | 正常、加载中（数字闪烁占位） | 班级面板数据 API |
| 知识点柱状图 | 有数据、无数据（隐藏） | 知识点热度图 API |
| 障碍分布图 | 三段扇区（概念/审题/表述） | 障碍分布 API |
| 成绩趋势图 | 有趋势、无趋势（显示"数据不足"） | 成绩趋势 API |
| 关注学生横条 | 有学生（横滑列表）、无学生（隐藏整个区域） | 诊断统计 API |

**关键交互**：
- 切换班级后，所有数据源重新加载
- 关注学生卡片点击跳转至学生管理页面，自动打开该学生的详情抽屉
- 图表支持响应式自适应宽度

**状态处理**：

| 状态 | 设计 |
|------|------|
| 加载态 | KPI 卡片显示骨架数字，图表区显示加载指示器 |
| 空态 | 新班级无考试记录时，显示"暂无考试数据，请先完成一次考试" |
| 错误态 | 图表渲染失败时，对应图表区显示"图表加载失败，点击重试" |
| 演示模式 | API 不可用时显示模拟数据标识，所有图表使用内置静态示例 |

**组件清单**：

| 组件 | 状态变体 | 数据来源 |
|------|---------|---------|
| 统计栏 | 正常、加载中 | 客户端聚合计算 |
| 搜索框 | 默认、输入中（实时搜索） | — |
| 筛选 chip | 未选中、选中 | — |
| 学生卡片 | 正常、hover（轻微阴影）、展开详情 | 学生列表 API（分页） |
| 分页控件 | 首页、中间页、末页，当前页高亮 | — |
| 详情抽屉 | 关闭、滑出、滑入关闭 | 学生详情 API |
| 添加学生弹窗 | 手动录入模式、邀请码模式 | — |
| 调班弹窗 | 班级选择列表 | 班级列表 API |

**关键交互**：

**状态处理**：

| 空态 | 搜索无结果时显示"未找到匹配的学生" |
| 错误态 | 详情抽屉加载失败时显示"加载失败，请关闭后重试" |

### 1.5 障碍诊断

**页面概述**：教师对班级考试结果进行障碍诊断。选择考试后触发诊断，结果以图表和分组列表展示。

**布局分区**：

| 分区 | 说明 |
|------|------|
| 工具栏 | 班级选择器 + 考试选择器 + "开始诊断"按钮 |
| 障碍分布图 | 左列：环形图（三类障碍占比） |
| 统计摘要 | 右列：三类障碍各一张统计卡片 |
| 分组学生列表 | 三个可折叠区段（按障碍类型分组），每组含学生行（含置信度进度条和薄弱知识点标签） |
| 学习计划面板 | 底部：可生成、预览、发送给学生的学习计划 |

**组件清单**：

| 组件 | 状态变体 | 数据来源 |
|------|---------|---------|
| 班级选择器 | 默认（第一个班级） | 班级列表 API |
| 考试选择器 | 默认（最近一次考试）、未选择 | 考试列表 API |
| 开始诊断按钮 | 默认、诊断中（loading + 禁用） | — |
| 障碍分布图 | 有数据、无数据（显示"请先运行诊断"） | 班级诊断统计 API |
| 分组学生列表 | 折叠、展开（手风琴模式，每次一个展开） | 班级障碍详情 API |
| 学生行 | 含置信度进度条（6px 高，灰色底 Oxford Blue 填充）、薄弱知识点标签 | — |
| 学习计划面板 | 未生成（显示生成按钮）、已生成（预览 + 发送按钮） | 学习计划 API |

**关键交互**：
- 班级+考试选择后点击"开始诊断"触发 LLM 分析，按钮显示 loading
- 分组列表手风琴模式：点击标题展开/折叠，同一时间只有一个展开
- 学生行的置信度 ≥0.8 为高置信、0.7-0.8 为中置信（标注"需关注"）、<0.7 为低置信（标注"建议复核"）

**状态处理**：

| 状态 | 设计 |
|------|------|
| 加载态 | 诊断按钮显示"诊断中..."并带旋转图标 |
| 空态 | 班级无考试记录时，考试选择器显示"暂无考试" |
| 错误态 | LLM 诊断失败时，Toast 显示"诊断失败，请重试" |

### 1.6 答题卡 OCR（上传与批改）
> 上传与批改结果合并在同一个页面（原型 ocr.html），与 41 号文档页面清单一致。

**页面概述**：教师上传答题卡图片进行 OCR 识别。支持拖拽上传和批量处理。

**布局分区**：

| 分区 | 说明 |
|------|------|
| 班级选择区 | 顶部下拉框，选择目标班级 |
| 拖拽上传区 | 中央 500×300px 虚线框，云上传图标 + 提示文字 + "选择文件"按钮 |
| 进度条区域 | 上传后显示处理进度百分比 |
| 识别结果表格 | 表格形式展示每张答题卡的学号、姓名、答案摘要、状态 |

**组件清单**：

| 组件 | 状态变体 | 数据来源 |
|------|---------|---------|
| 班级选择器 | 默认（第一个班级） | 班级列表 API |
| 上传区域 | 默认（虚线框）、拖拽悬停（高亮边框）、上传中（进度显示） | — |
| 进度条 | 0%-100%，填充动画 | OCR 任务状态轮询 |
| 结果表格 | 每行含学号、姓名、答案摘要、状态徽章（done=绿/processing=黄/failed=红）、重试按钮 | OCR 任务列表 API |
| 重试按钮 | 仅失败任务显示 | — |

**关键交互**：
- 拖拽图片到上传区域自动上传，支持 JPG/PNG/BMP/WEBP/PDF 格式
- 上传后自动开始 OCR 识别，5 秒轮询更新进度
- 教师在表格中可直接修改识别内容（学号、姓名、答案）
- 单文件上限 10 MB，前端单批上限 10 张

**状态处理**：

| 状态 | 设计 |
|------|------|
| 加载态 | 上传区显示上传进度条，结果表格逐行出现 |
| 空态 | 未上传时显示上传图标 + "点击或拖拽上传答题卡" |
| 错误态 | OCR 识别失败时，该行显示红色徽章 + [重试]按钮 |

#### 1.6.1 答题卡批改（结果展示）

**页面概述**：对已完成 OCR 识别的答题卡进行 LLM 批改，查看和确认批改结果。

**布局分区**：

| 分区 | 说明 |
|------|------|
| 上传区域 | 顶部，支持点击或拖拽上传（单批上限 10 张） |

| 历史批次列表 | 按批次展示，每批含任务状态和进度 |

**状态处理**：同 1.6 OCR 上传。

## 二、学生端（6 个页面）

> 学生端全部为移动端 430px 视口设计。6 个独立 HTML 页面通过底部 TabBar（AI 助教 / 练习 / 错题 / 我的）组织导航。

### 2.1 AI 助教对话

**页面概述**：学生端入口页面。与 AI 化学助教进行对话，提问化学问题、获取辅导和实验模拟。

**布局分区**：

| 分区 | 说明 |
|------|------|
| 顶部标题栏 | 56px，Oxford Blue 背景：汉堡菜单 + "ChemAI 助教" + 新建对话图标 |
| 侧边栏抽屉 | 280px，左侧滑出：学生头像+姓名+班级 + 历史对话列表 + 退出登录 |
| 对话区 | AI 气泡（Teal 浅色 #e0f2f1，左对齐，圆角 12px）+ 用户气泡（白底浅灰边框，右对齐） |
| 快捷芯片行 | 横向可滚动：5 个预设提示（实验/讲解/配平等） |
| 输入区 | 底部固定 70px：附件图标 + 输入框 + 圆形发送按钮 |
| 底部 TabBar | 56px，4 Tab（AI 助教 / 练习 / 错题 / 我的），当前激活为 Oxford Blue |

**关键交互**：
- 汉堡菜单点击：侧边栏从左侧滑入（280px），遮罩层点击关闭
- 附件按钮支持拍照上传题目
- 化学式支持 KaTeX 渲染

**状态处理**：

| 状态 | 设计 |
|------|------|
| 加载态 | 对话区显示"正在连接助教..." |
| 空态 | 新对话显示欢迎语 + 5 个快捷芯片 + 输入框 |
| 错误态 | 连接中断时显示"连接失败，点击重试" |

---

### 2.2 练习做题

**页面概述**：学生完成教师布置或系统自动生成的练习题。

**布局分区**：

| 分区 | 说明 |
|------|------|
| 顶部标题栏 | 返回箭头 + "练习" + 进度"X/Y" |

## 四、跨页面交互协议

### 4.1 Agent 导航桥接

Agent 可通过 SSE 事件触发页面跳转和数据传递：

1. Agent 工具返回 `_route` 字段 → SSE 适配器发送 `navigate` / `populate` / `action` 事件
2. 前端将导航数据写入页面桥接存储
3. 目标页面加载时读取桥接数据，自动配置页面状态（如打开指定学生详情抽屉、加载指定考试等）

### 4.2 页面间数据传递

| 场景 | 触发方 | 目标页 | 传递数据 |
|------|--------|--------|---------|
| 学情面板 → 学生管理 | 点击关注学生卡片 | 学生管理页 | 学生 ID（自动打开详情抽屉） |
| Agent → 出题工作台 | Agent 返回 exam-workbench 组件 | 考试工作台 | 知识点/难度/题型参数 |
| Agent → 诊断面板 | Agent 返回 diagnosis 组件 | 障碍诊断 | 班级 ID + 考试 ID |
| 练习 → 错题本 | 练习提交后 | 错题本 | 新增错题数据 |
