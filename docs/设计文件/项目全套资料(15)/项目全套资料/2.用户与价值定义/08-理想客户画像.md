## 一、ICP 核心定义

### 一句话 ICP

> **湖南省内地级市以上重点高中的高三化学备课组**，备课组长教龄 8-15 年，组内有 2-6 位化学老师，对信息化工具持开放态度，有提高教学质量的考核压力。

### 为什么是这个 ICP？

| 维度 | 选择逻辑 | 排除逻辑 |
|------|---------|---------|
| **高三而非高一** | 高三考试频次最高（周练+月考+模考），诊断需求最迫切，使用频次驱动留存 | 高一考试频次低（期中+期末为主），诊断工具使用频率不足以形成习惯 |
| **重点高中而非普通高中** | 重点高中有信息化预算、老师技术水平较高、教学质量考核压力更大 | 普通高中预算不足 OR 升学压力不足以驱动工具采购 |
| **地级市+省会** | 五城聚焦（长沙/株洲/湘潭/衡阳/岳阳）——地级市是竞争洼地，长沙作为省会品牌标杆城市后期进入 | 乡镇农村高中信息化预算不足、网络条件差 |
| **湖南而非全国** | 种子用户所在地、创始人社交网络半径内、高考大省需求典型 | 跨省推广在种子期分散精力 |
| **备课组长而非普通老师** | 备课组长有推广权（带动全组使用）+ 有仪表盘需求（全年级数据）+ 有采购建议权 | 普通老师推不动学校采购决策，组内扩散速度慢 |

## 二、ICP 详细画像

### 2.1 学校画像（Firmographics -- 购买单位）

| 维度 | ICP 描述 | 排除标准（NOT ICP） | 判别方法 |
|------|---------|-------------------|---------|
| **学校类型** | 公立重点高中（省级示范性高中） | 职高、中职、国际学校（课程体系不同）、民办高中（采购决策机制不同） | 学校官网/教育局公示名单 |
| **所在地** | 湖南省地级市市区及省会（长沙/株洲/湘潭/衡阳/岳阳/常德/郴州/怀化等） | 乡镇农村高中（信息化预算不足、网络条件差） | 学校地址和教育统计分类 |
| **规模** | 每个年级 8-24 个班，在校生 1200-4000 人 | 全校 < 500 人的微型高中（化学老师可能只有 1-2 人，无备课组概念） | 学校官网/教育局统计数据 |
| **信息化基础** | 已有校园网络和基础 IT 设施，有信息中心管理员，老师日常使用电脑办公 | 连投影仪都没配齐的学校；网络条件差导致 OCR 上传不稳定 | 实地观察或通过种子老师了解 |
| **预算** | 年度信息化预算 >= 5 万元 | 零信息化预算的学校（几乎无法通过任何流程完成采购） | 种子用户摸底 |
| **升学压力** | 一本率 30-60%（"中等偏上"的重点高中 -- 有上升诉求，工具能带来实际提升空间） | 一本率 > 90%（顶级名校 -- 不太需要工具辅助，成绩已经很好）或 < 10%（薄弱学校 -- 基础太差，先解决别的问题，诊断工具非优先） | 公开的高考数据 |
| **选考化学人数** | 化学选考人数多（>= 年级人数的 40%），化学是学校的"主力学科"之一 | 化学选考人数极少（< 20%）| 种子用户摸底 |
| **学科组规模** | 化学组 >= 4 位老师（含 1-2 位年轻老师，3 年以下教龄） | 化学组只有 1-2 位老师（没有备课组概念，没有跨班对比需求） | 种子用户摸底 |
| **现有使用工具** | 已有学科网/组卷网会员或其他教学信息化工具（说明有信息化预算和使用习惯） | 从未采购过任何教学信息化工具（说明对信息化工具有抵触） | 种子用户摸底 |

### 2.2 化学教研组画像（使用单位）

| 维度 | ICP 描述 | 细分数值/范围 |
|------|---------|-------------|
| **备课组长** | 教龄 8-15 年，带过高三大循环（至少一轮），有教研成果意识（发表过文章或参加过省级教研活动）、对新技术有好奇心但要求"5 分钟上手" | 教龄范围可放宽到 5-20 年 |
| **组内规模** | 2-6 位化学老师（含 1-2 位年轻老师，教龄 < 3 年） | 年轻老师越多 -> 对标准化诊断的需求越强（需要"扶正"年轻老师的讲评方向） |
| **教学压力** | 化学选考人数多、等级赋分竞争激烈、"每分必争" | 等级赋分制下 1 分之差 = 赋分 3-5 分之差 |
| **现有工具** | 已有学科网/组卷网会员（说明有信息化预算和使用习惯），但没有教学诊断工具 | "用了学科网找题 + Excel 统计 = 现有工作流" |
| **痛点特征** | 备课组长在每次考试后花大量时间手工统计错题（6-10 小时/次）、组里年轻老师"讲评方向跑偏"需要纠正、家长会时缺少可视化的学情数据 | 量化痛点：每月至少 1 次月考 -> 每年 30+ 个工作日在统计上 |
| **对 ChemAI 的期望** | 不是替代老师的判断，而是"把统计工作做了，让老师把时间放在判断上" | 期望值匹配产品定位（"AI 助教"而非"AI 老师"） |
| **校内推广意愿** | 愿意在备课组会议上分享 ChemAI 的使用体验和数据 | "数据驱动的教研"是其职业形象的一部分 |

### 2.3 决策流程画像

| 维度 | 描述 | ChemAI 的应对 |
|------|------|-------------|
| **决策路径** | 备课组长提出需求 -> 教研主任支持 -> 分管副校长审批 -> 校长同意 -> 总务处采购 | 从备课组长切入，帮助备课组长"向上卖"（提供向教研主任/校长汇报的素材） |
| **关键影响者** | 备课组长（发起者）、教研主任（背书者） | 备课组长是主要服务对象，但也要确保教研主任获得正面印象 |
| **关键决策者** | 分管副校长（预算审批者） | 为副校长准备"一句话决策理由"：提升化学学科教学质量 |
| **决策周期** | 从首次接触到签约：2-4 个月（种子期，有人际信任缩短到 2-4 周） | 种子期靠关系缩短，推广期靠案例和数据缩短 |
| **决策驱动因素** | "这个工具能提升化学成绩"的证据（案例/数据） > 功能列表 > 价格 | 积累案例是最高优先级的销售准备 |
| **采购阻力** | "之前没听说过"（品牌缺失）、"用起来麻烦吗"（实施顾虑）、"花费值得吗"（ROI 不明确） | 免费试用降低决策门槛；数据展示 ROI |
| **预算额度** | 每班 3000-8000 元/年通常在"备课组可自主决定"的额度内（不需要校级审批） | 按班计价的设计是刻意的低门槛策略 |

## 三、ICP 的 JTBD（Jobs to Be Done）

### 备课组长的功能型 JTBD

> 当一次月考结束后，**快速拿到全年级的化学错题诊断报告**，让备课组统一讲评方向，让年轻老师的讲评不跑偏。

**成功标准**：
- 从"考完"到"拿到完整分析报告"的时间 <= 1 小时（对比手工统计的 6-10 小时）
- 报告中每道错题标注了病因类型（概念/审题/表达）
- 报告自动按"讲评优先级"排序（高/中/低）

### 备课组长的情感型 JTBD

> 在学校层面**证明"化学组的教研是有数据支撑的"**，在年终总结和评优时有可视化成果展示。

**成功标准**：
- 学期末能拉出化学学科的"知识点薄弱->改进"的可视化趋势图
- 在教研主任和校长面前，教研汇报有"硬数据"而不是"我感觉"

### 备课组长的社会型 JTBD

> 在市级教研交流中**被同行认可为"用数据驱动教学的先行者"**。

**成功标准**：
- 在省级/市级教研会议上能展示"基于 ChemAI 的化学教学数据分析"
- 同行来问"你们学校用的什么工具？"

### 化学老师的增量 JTBD（除备课组长之外的个人使用者）

> 当批改完成试卷后，**一眼看出自己班和其他班的差异**，知道自己的教学在哪个知识点上可能出了问题。

**成功标准**：
- 仪表盘上能直观看到"本班 vs 年级平均"的对比
- 自己的教学薄弱点被数据揭示（而非自我感觉良好）

## 四、ICP 的痛点深度量化

| 痛点 | 当前做法 | 痛点程度 | 定量影响 | 替代方案的成本 |
|------|---------|---------|---------|-------------|
| **考后统计耗时** | 手工画"正"字统计 + Excel 汇总 | 🔴 极高 | 每次月考后 6-10 小时，一年约 30 个工作日（相当于一个半月的教学时间） | 买讯飞阅卷系统：10-50 万/校 |
| **年轻老师判断不准** | 组长逐个复核年轻老师的讲评方案 | 🟡 中高 | 组长额外增加 2-3 小时复核时间 | 多做集体备课：额外 2-3 小时/周 |
| **家长会"没干货"** | 只能念分数段、班级排名 | 🟡 中 | 家长满意度低，对老师的专业信任受损 | 买学情分析系统：5-20 万/年 |
| **学期末无可视化成果** | 凭记忆和纸质记录写总结 | 🟡 中 | 教学总结缺少量化支撑，评优/评职称时吃亏 | 手工做 Excel 总结：额外 4-6 小时 |
| **知识盲区积累不追踪** | 凭老师个人记忆追查学生往期弱点 | 🟡 中 | 一个学生在"氧化还原"上错了 5 次但老师可能只记得最近 2 次 | 手动翻纸质试卷：不可持续 |

## 五、定量 ICP 评分模型

### 5.1 评分维度与权重

| 维度 | 权重 | 评分标准 |
|------|------|---------|
| **学校类型匹配度** | 20% | 重点高中=10; 普通高中=6; 职高/国际=0 |
| **地理位置** | 15% | 湖南地级市=10; 湖南省会=8; 外省地级市=5; 乡镇=0 |
| **化学选考率** | 15% | >=50%=10; 30-50%=8; 20-30%=5; <20%=2 |
| **学科组规模** | 10% | >=4人=10; 3人=8; 2人=5; 1人=2 |
| **备课组长教龄** | 10% | 8-15年=10; 5-8年=8; 15-20年=6; <5或>20=3 |
| **信息化预算** | 15% | >=10万=10; 5-10万=8; 2-5万=5; <2万=2; 0=0 |
| **现有工具使用** | 5% | 已有学科网/组卷网=10; 有其他=6; 无=2 |
| **升学压力(一本率)** | 5% | 30-60%=10; 10-30%=7; 60-90%=5; <10%或>90%=3 |
| **教研活跃度** | 5% | 备课组长参与过省级教研=10; 市级=7; 校级=4; 无=0 |

### 5.2 评分计算公式

```
ICP Score = Σ(维度得分 x 权重)

分级：
>= 8.5 : Tier 1（最高优先级，立即投入销售/服务资源）
7.0-8.4 : Tier 2（高优先级，有资源时投入）
5.0-6.9 : Tier 3（低优先级，不主动拓展但近水楼台可接）
< 5.0 : NOT ICP（不投入资源）
```

### 5.3 ICP 评分三个示例

#### 示例 A：理想 ICP（Tier 1）

湖南衡阳市某省级示范性高中（在校生 2400 人）
- 学校类型：重点高中=10 x 0.20 = 2.0
- 地理位置：衡阳=10 x 0.15 = 1.5
- 化学选考率：55%=10 x 0.15 = 1.5
- 学科组规模：5 人=10 x 0.10 = 1.0
- 备课组长教龄：12 年=10 x 0.10 = 1.0
- 信息化预算：8 万=8 x 0.15 = 1.2
- 现有工具：有学科网=10 x 0.05 = 0.5
- 升学压力：一本率 42%=10 x 0.05 = 0.5
- 教研活跃度：省级=10 x 0.05 = 0.5
- **总分：9.7 -> Tier 1**

#### 示例 B：边缘 ICP（Tier 2）

湖南长沙市某普通高中（在校生 1800 人）
- 学校类型：普通高中=6 x 0.20 = 1.2
- 地理位置：长沙=8 x 0.15 = 1.2
- 化学选考率：40%=8 x 0.15 = 1.2
- 学科组规模：3 人=8 x 0.10 = 0.8
- 备课组长教龄：22 年=3 x 0.10 = 0.3
- 信息化预算：5 万=8 x 0.15 = 1.2
- 现有工具：有其他=6 x 0.05 = 0.3
- 升学压力：一本率 25%=7 x 0.05 = 0.35
- 教研活跃度：市级=7 x 0.05 = 0.35
- **总分：6.9 -> Tier 2**

#### 示例 C：NOT ICP

湖南某县城普通高中（在校生 600 人）
- 学校类型：普通高中=6 x 0.20 = 1.2
- 地理位置：县城=5 x 0.15 = 0.75
- 化学选考率：25%=5 x 0.15 = 0.75
- 学科组规模：2 人=5 x 0.10 = 0.5
- 备课组长教龄：25 年=3 x 0.10 = 0.3
- 信息化预算：1 万=2 x 0.15 = 0.3
- 现有工具：无=2 x 0.05 = 0.1

- 教研活跃度：无=0 x 0.05 = 0
- **总分：4.05 -> NOT ICP**

## 六、ICP 的分层树（Tier 1/2/3）

### Tier 1（最高优先级，前 10 所学校）

**画像描述**：湖南省地级市重点高中，高三化学备课组长驱动，化学选考率 >= 50%，化学组 >= 4 人。

**典型学校特征**：
- 省级示范性高中
- 在校生 1500-3000 人
- 化学选考人数 >= 年级人数的 50%
- 备课组长教龄 8-15 年，有省级教研参与经验
- 已有学科网/组卷网会员
- 一本率 30-60%（有上升诉求）

**目标数量（12 个月内）**：8-12 所

**服务策略**：
- 创始人亲自 onboard（手把手 + 驻校 1-2 天）
- 定制化学期报告（免费赠送，展示数据价值）
- 备课组长作为"种子推广者"培养（帮助其在省级教研活动中分享 ChemAI 使用案例）
- 每两周 1 次主动回访

### Tier 2（高优先级，第 11-30 所学校）

**画像描述**：湖南省会/地级市重点或普通高中，化学选考率 30-50%，学科组 3-4 人。或外省高考大省（湖北、山东、江苏）的地级市重点高中。

**典型学校特征**：
- 重点或普通高中
- 在校生 1000-3000 人
- 化学选考人数 30-50%
- 备课组长教龄 5-20 年
- 信息化预算 >= 5 万

**目标数量（12 个月内）**：10-15 所（湖南省内 5-8 所 + 外省试探性 2-3 所）

**服务策略**：
- 标准化 onboarding（视频 + 文档辅助，减少一对一时间）
- 每月 1 次主动回访
- 利用 Tier 1 学校的案例作为"社会证明"

### Tier 3（低优先级，第 31+ 所学校）

**画像描述**：规模较小的普通高中，或化学不是主力学科的学校。

**目标数量（12 个月内）**：不主动拓展，如果近水楼台（地理上接近现有客户、转介绍渠道进入）可接。

**服务策略**：
- 自助 onboarding（全自助 + 在线帮助中心）
- 仅被动响应（不主动回访）
- 如果学校规模太小 -> 评估是否值得维护

## 七、负向 ICP（Negative ICP）-- 谁不该碰

### 7.1 详细负向 ICP 画像

以下类型的学校和老师是明确的"不该投入销售/服务资源"的对象：

| 负向 ICP | 原因 | 判别信号 | 如果已经在接触怎么办 |
|----------|------|---------|-------------------|
| **教龄 > 25 年且明确表示"不用智能手机/电脑"的老师** | 行为改变的成本太高。即使产品好，老师也不会用。种子期不能花时间在"最难改变的人"上。 | "我用纸笔几十年了，不用改" | 礼貌结束对话。如果他是备课组长（权力高但使用意愿低），可以让他指定组里年轻老师做"试点联系人" |
| **学校最近刚采购了讯飞阅卷系统（< 6 个月）** | 替代成本高（已投入 10-50 万），且讯飞已有基础诊断功能。学校不太可能在短期内再采购一个化学专项工具。 | "我们刚买了讯飞，先用一阵看看" | 保持联系但不要硬推。等讯飞使用一段时间后（化学诊断深度不足的痛点暴露了），再适时跟进 |
| **化学不是该校的重点学科** | 学校对化学的投入意愿低（选考人数少、学科组弱）。诊断工具的价值难以体现。 | 化学选考率 < 20%；化学组 < 3 人 | 不投入。如果学校规模大（其他学科有预算），可以等扩展到其他学科后再接触 |
| **学校正在经历合并/搬迁/校长换届等重大变动** | 决策能力冻结。所有采购决定都会推迟到变动结束后。 | 听到"我们学校现在/明年..." + 重大变动关键词 | 记录变动时间表，在变动结束后 1 个月再跟进 |
| **"免费党"学校** | 不是预算不够，而是"能免费绝不付费"的采购文化。即使先用免费版，到付费时也会流失。 | "有没有更便宜的方案"/"免费版够用了吧" | 解释 ChemAI 的定价是基于价值的，不参与"免费竞争"。如果对方坚持 -> 不投入 |
| **纯粹想"比价"的采购办驱动型** | 备课组无真实需求，采购办在"货比三家"阶段。即使签约，使用率也会极低（因为不是老师想要的）。 | 接触方是采购办而非化学组；问题集中在"多少钱""有什么资质"而非"能解决什么问题" | 引导到化学组层面（"不如让化学老师先试用一下，看看是否适合？"） |
| **国际学校/国际课程体系** | 课程体系不同（A-Level/IB/AP 化学 vs 中国高考化学），知识框架、题型、诊断标准不同。 | "我们用的是 A-Level" | 不投入。当前产品不覆盖国际课程，需要大量适配工作 |

### 7.2 负向 ICP 识别清单（种子期快速筛查）

在与潜在学校/老师接触时，用以下 5 个问题快速筛查是否为负向 ICP：

| 问题 | 负向 ICP 回答 | 正向 ICP 回答 |
|------|-------------|-------------|
| 1. 你们化学组有多少位老师？ | "就我一个" / "2 个" | "4-6 个，还有一个刚毕业的" |
| 2. 每次月考后你怎么做错题分析的？ | "我差不多看一眼就知道学生哪里错了" | "我要花大半个周末来统计，头疼死了" |
| 3. 学校有什么教学信息化工具在用吗？ | "没有" / "买过一个但没人用" | "学科网、组卷网都在用" |
| 4. 你们学校的化学选考情况怎么样？ | "不多，好多学生不选化学" | "大部分学生选化学，竞争很激烈" |
| 5. 你参加过省级或市级的化学教研活动吗？ | "没有" | "去年参加了省化学年会，还做了一个分享" |

**如果 5 个问题中有 2 个以上是负向 ICP 回答 -> 标记为"需要进一步评估"**
**如果 5 个问题中有 3 个以上是负向 ICP 回答 -> 标记为 NOT ICP**

## 八、ICP 客户旅程地图

### 8.1 六阶段旅程

```
意识 -> 考虑 -> 试用 -> 采购 -> 上线 -> 倡导
(1-4周) (2-4周) (4-8周) (2-4周) (1-2周) (持续)
```

### 阶段 1：意识（Awareness）

**客户在想什么**：
- "有没有工具能帮我省掉考后统计的时间？"
- "AI 教育工具靠谱吗？会不会用起来很麻烦？"
- "有没有别的学校在用？效果怎么样？"

**ChemAI 的触达方式**：
- 省级化学教研会议（备课组长的自然聚集地）
- 种子老师的转介绍（"我们学校在用，你要不要试试"）
- 化学教师微信群（非广告形式的案例分享）
- 学科网/组卷网的渠道合作（如达成）

**关键指标**：触达 -> 有兴趣了解的比例

**关键内容资产**：
- 2 分钟产品演示视频（"拍照->出报告"全流程）
- 1 页产品简介 PDF（学校领导看的版本）
- 同行案例（"XX 学校高三化学组正在使用"）

### 阶段 2：考虑（Consideration）

**客户在想什么**：
- "这个和讯飞/学科网有什么不同？"
- "我们学校能买得起吗？"
- "化学组的老师会用吗？会不会增加负担？"

**ChemAI 的推进方式**：
- 1v1 demo（20 分钟）：真实演示拍照->诊断->报告全流程
- 竞品对比文档（ChemAI vs 讯飞 vs 学科网）
- 试用邀请：免费试用 3 个月（包括 1 次月考的完整流程）

**关键指标**：demo -> 同意试用的转化率

**关键内容资产**：
- 竞品对比表（详见 「04-竞品分析」）
- 试用协议模板
- "试用前准备"checklist（需要学校准备什么）

### 阶段 3：试用（Trial）

**客户在想什么**：
- "这个真的能帮我省时间吗？"
- "诊断准确吗？和我的判断一致吗？"
- "学生能用到吗？家长能看到报告吗？"

**ChemAI 的推进方式**：
- 第一次使用全程陪同（种子期：创始人驻校；推广期：在线远程指导）
- 第一次考试后 24 小时内主动回访："报告有帮到你吗？"
- 收集使用数据和反馈（OCR 准确率、诊断采纳率、使用频率）

**关键指标**：试用 -> 满意的比例；周活跃率 >= 80%

**关键内容资产**：
- 首次使用指南（图文或视频）
- 常见问题 FAQ
- "给化学老师的 3 个使用小技巧"

**"Aha Moment"设计**：
- 目标：试用老师第一次使用后 5 分钟内感受到"这就是我要的"
- 路径：上传答题卡 -> 实时进度的流式反馈（"正在识别第 3 张..."） -> 5 分钟内出第一张答题卡的报告（整班 90 人 ≤ 15 分钟） -> 老师在报告中看到"平时需要 2 小时统计才能看到的信息"

### 阶段 4：采购（Purchase）

**客户在想什么**：
- "多少钱？值不值？"
- "采购流程怎么走？要审批多久？"
- "明年还继续用吗？"

**ChemAI 的推进方式**：
- 提供试用期数据总结（"试用期间，您累计节省了 X 小时的统计时间"）
- 提供报价方案（按班计价）
- 帮助备课组长"向上卖"（提供向教研主任/校长汇报的素材 -- 1 页 PPT 模板）
- 灵活的合同条款（按学期付款、随时可退等降低决策风险）

**关键指标**：试用 -> 签约的转化率（目标 >= 70%）

**关键内容资产**：
- 报价方案和合同模板
- "向领导汇报"1 页 PPT 模板
- 试用期数据总结报告

### 阶段 5：上线（Onboarding）

**客户在想什么**：
- "其他老师怎么加进来？"
- "学生怎么注册？"
- "会不会增加 IT 管理员的负担？"

**ChemAI 的推进方式**：
- 标准化 onboarding 流程（种子期：1-2 天驻校；推广期：远程 + 培训材料）
- 培训化学组全体老师（30 分钟工作组）
- 帮备课组长设置好第一个班级和第一次考试
- 配置通知推送和家长端（上线后执行）

**关键指标**：onboarding -> 全组激活的时间（目标 <= 14 天）

**关键内容资产**：
- 教师培训材料（视频 + 文档）
- 学生注册指南（1 页说明发给班主任）
- 家长端激活指南（微信推送模板）

### 阶段 6：倡导（Advocacy）

**客户在想什么**：
- "要不要推荐给其他学校的同行？"
- "能不能在教研会上分享使用经验？"
- "能不能和 ChemAI 团队一起写篇教研文章？"

**ChemAI 的推进方式**：
- 识别"超级用户"（使用频次最高、主动给反馈、在同行中有影响力的老师）
- 邀请超级用户参与产品改进讨论（"内测组"）
- 支持超级用户在省级教研活动中分享（提供数据、图表和演讲素材）
- 建立"ChemAI 种子教师"认证和激励机制

**关键指标**：转介绍率 >= 40%；NPS >= +30

**关键内容资产**：
- "ChemAI 使用案例"模板（供老师在教研会上展示）
- 教研文章联合撰写邀请
- "种子教师"认证体系

## 九、ICP 验证方法论

### 9.1 种子期验证计划（前 90 天）

| 假设 | 验证方法 | 验证标准 | 数据来源 | 验证时间 |
|------|---------|---------|---------|---------|
| H1: 高三备课组长有强烈的"考后分析耗时"痛点 | 种子用户深度访谈（5 位以上） | >= 4/5 位老师自述"这是我最头疼的事之一" | 1v1 深度访谈 | 前 30 天 |
| H2: 备课组长愿意在日常工作流中使用新工具 | 种子用户周活跃率和留存曲线 | 周活跃率 >= 80% 在种子期持续 >= 4 周 | 系统埋点数据 | 前 60 天 |
| H3: 备课组长能够带动组内其他老师使用 | 校内扩散率 | 种子学校内 >= 50% 的化学老师使用 | 系统用户数据 | 前 90 天 |
| H4: 学校有信息化预算用于教学诊断工具 | 种子学校采购意愿调研 | >= 2/3 所学校表达"愿意付费" | 直接询问 + 试用后付费意愿调研 | 前 90 天 |
| H5: 诊断准确率达标 | 双盲评测（系统 vs 资深老师） | 一致率 >= 80% | 双盲评测报告 | 前 60 天 |
| H6: 家长端有价值 | 家长周报打开率 | >= 50% | 推送数据 | 家长端上线后 30 天 |

### 9.2 验证访谈提纲（备课组长版，45 分钟）

**Part 1：了解现状（10 分钟）**
1. "你们现在考试后怎么做错题分析的？整个流程是什么样的？"
2. "这个过程大概要花多长时间？"
3. "这个过程中最让你头疼的是什么？"
4. "你试过用什么工具或方法来解决这个问题吗？效果怎么样？"

**Part 2：使用体验（15 分钟）**
5. "第一次用 ChemAI 的时候，你觉得怎么样？有什么让你惊喜的地方？有什么让你困惑的地方？"
6. "你现在用 ChemAI 的频率是怎样的？什么时候会用，什么时候不会用？"
7. "诊断报告中的'概念障碍/审题障碍/表达障碍'分类，你觉得准确吗？有遇到过明显不对的判断吗？"
8. "和之前手工统计相比，最大的变化是什么？"

**Part 3：价值感知（10 分钟）**
9. "如果 ChemAI 明天突然不能用了，你会有什么感受？你会怎么办？"
10. "你会推荐给其他学校的化学老师吗？你会怎么推荐？"
11. "如果学校需要为 ChemAI 付费（比如 3000-5000 元/班/年），你觉得这个价格怎么样？你愿意推动学校购买吗？"

**Part 4：改进方向（10 分钟）**
12. "你觉得 ChemAI 最需要改进的是什么？"
13. "有没有什么功能是你觉得'应该有但现在没有'的？"
14. "如果 ChemAI 只能做一件事来让你更满意，那件事是什么？"

### 9.3 验证数据 vs 感知数据的交叉分析

| 验证维度 | 感知数据（老师说） | 行为数据（系统记录） | 一致性判断 |
|---------|-----------------|-------------------|-----------|
| 使用频率 | "每周都用" | 实际周活跃频率 | 如果差距 >= 30% -> 礼貌性好评 |
| 诊断信任度 | "大部分判断是准的" | 老师手动修改诊断的比例 | 如果修改比例 > 20% -> 口头表扬但实际不信任 |
| 省时间 | "确实省了很多时间" | 从上传到查看报告的完整时间 | 如果时间节省 < 50% -> "客气" |
| 推荐意愿 | "肯定推荐给同事" | 实际转介绍的数量 | 如果 NPS 高但转介绍 0 -> 礼貌性好评 |

## 十、基于 ICP 的线索评分模型

### 10.1 线索评分维度（用于推广期线索排序）

| 维度 | 分值 | 评分标准 |
|------|------|---------|
| **学校 ICP 匹配度** | 0-30 | 基于 ICP 评分模型的映射：9-10分->30; 7-8.9->20; 5-6.9->10; <5->0 |
| **接触来源** | 0-20 | 种子老师转介绍=20; 教研会议接触=15; 微信社群自发询问=10; 冷触达=5 |
| **需求紧迫度** | 0-20 | 主动提出"我们急需这样的工具"=20; 询问价格和试用=15; 泛泛了解=5 |
| **决策权** | 0-15 | 备课组长+有采购建议权=15; 备课组长无采购权=10; 普通老师=5; 非教师角色=0 |
| **时间窗口** | 0-10 | 距离开学/考试 < 2周=10; < 1月=5; > 1月=0 |
| **竞品使用情况** | 0-5 | 未用竞品=5; 用学科网=3; 用讯飞(>6月)=1; 用讯飞(<6月)=0 |

### 10.2 评分分级

```
>= 80 分：热线索（Hot Lead） -> 24 小时内创始人亲自跟进
60-79 分：温线索（Warm Lead） -> 48 小时内触达，发送产品资料 + 试用邀请
40-59 分：冷线索（Cold Lead） -> 加入培育流程（推送案例、教研文章等）
< 40 分：非线索    -> 不投入，保留在联系人库
```

## 十一、三个 ICP 客户案例研究（假设但基于真实数据）

### 案例 1：Tier 1 -- 某省级示范性高中高三化学备课组长（代号"备课组长A"）

**学校背景**：
- 省级示范性高中，在校生 2400 人，每个年级 16 个班
- 化学选考率 55%，高三年级共有 9 个化学班
- 化学组 5 位老师（备课组长A教龄 12 年 + 2 位教龄 8-10 年的骨干 + 2 位教龄 1-3 年的新手）
- 已有学科网会员（年级统一采购，2000 元/年）
- 一本率 42%（在当地重点高中中处于中游，有上升压力）

**备课组长A的痛点**：
- 每次月考后需要花 8-10 小时手工统计 9 个班的化学错题（按知识点分类）
- 两位新手老师的讲评方案经常"跑偏"（把审题错误当成概念错误来处理）
- 备课组长A需要在复核新手老师的讲评方案上额外花 2-3 小时/次
- 学期末写教研总结时，只能凭印象写"本学期重点抓了氧化还原"，没有量化数据

**接触 ChemAI 的路径**：
- 第一次听说：省化学年会上听到另一个学校的老师提到"在用 AI 做化学诊断"
- 试用决定：备课组长A主动联系了 ChemAI 创始人，申请试用
- 首次使用体验：第一次月考后上传了 9 个班的答题卡，15 分钟后拿到了全年级分析报告。"我对着屏幕看了 10 分钟，然后把那份报告打印出来，在备课组会上给其他老师看了"

**使用效果（假设 -- 3 个月后）**：
- 考后分析时间从 8-10 小时降到 1 小时（节省 ~90%）
- 新手老师复核时间从 2-3 小时降到 30 分钟（诊断报告给了新手老师更好的方向指引）
- 备课组会的"讲评方向争论"变成了"围绕诊断数据的讨论"（质的变化）
- 备课组长A在市级教研活动中分享了"基于 AI 诊断的化学教研实践"，获得了同行的积极反馈

**续约决定**：
- 学期结束后备课组长A向学校提交了下年度采购申请（全校 9 个班 x 5000 元 = 45,000 元/年）
- 学校批准了这笔预算（教育局已把"信息化教学工具"纳入常规预算科目）

**对 ChemAI 的价值**：
- 完整的 1 个标杆案例（可用于销售材料和教研会议分享）
- 转介绍来源：备课组长A在市教研活动中至少为 ChemAI 带来了 3 个新的意向学校
- 产品反馈来源：新手老师的讲评方案改进是 ChemAI 诊断准确率持续提升的重要反馈来源

### 案例 2：Tier 2 -- 某地级市普通高中化学教师（代号"教师B"）

**学校背景**：
- 市区普通高中（非重点），在校生 1800 人
- 化学选考率 35%，高三年级共 6 个化学班
- 化学组 3 位老师（教师B教龄 18 年，另外 2 位教龄 5-10 年）
- 没有学科网会员，信息化工具使用较少
- 一本率 25%（属于"争取突破 30%"的档次）

**教师B的痛点**：
- 考后统计时间约 4-5 小时/次（学校规模小，班级少，但统计方法原始）
- 最大的痛点是"不知道学生到底哪里弱" -- 凭经验感觉"好像有机化学都不太好"，但不确定
- 学校信息化预算有限（~3 万/年），之前买过一个阅卷系统但"老师不会用"就搁置了

**接触 ChemAI 的路径**：
- 备课组长A（案例 1）在市教研会上分享后推荐
- 教师B抱着"反正免费试用，不花钱"的心态开始了

**试用体验**：
- 第一次使用后，"我终于知道了一直凭感觉的事 -- 原来学生最弱的确实是同分异构体，但手性碳的判断其实还行"
- 因为学校规模小（6 个班），试用期间教师B几乎"每个功能都试过一遍"
- 学生端报告被推送到班级群后，有几个家长私信教师B"这个报告能不能每周都发"（家长端需求的自然验证）

**采购挑战**：
- 学校预算只有 3 万/年，全买别的不够。教师B需要说服校长单独为化学工具批一笔预算
- 教师B用试用期的数据（"这学期化学组的期末正确率比上学期提升了 8%"）说服校长
- 最终签了 4 个班 x 4000 元 = 16,000 元/年（学校优惠了部分价格）

**对 ChemAI 的价值**：
- 验证了"普通高中也能成为客户"（ICP 的边缘案例）
- 家长端需求的自然验证（家长主动要求每周报告）
- 小型学校的运营成本验证（6 个班的并发处理性能测试）

### 案例 3：NOT ICP -- 某县城高中的"弯路"

**学校背景**：
- 湖南某县城普通高中，在校生 600 人
- 化学选考率 20%，高三年级仅 2 个化学班
- 化学组 2 位老师（教龄均 > 20 年）
- 无信息化预算，无学科网会员
- 一本率 < 10%

**发生了什么**：
- 学校的一位老师通过朋友圈了解到 ChemAI，主动申请了免费试用
- 试用后发现：(a) 学校网络太差，上传答题卡经常超时；(b) 只有 2 个班，统计量本就不大（"我自己统计也就 1 小时"）；(c) 老教师对新工具的学习意愿不高

**浪费的资源**：
- 创始人花了一个下午做远程 onboarding（时间是种子期最宝贵的资源）
- 老师用了 2 次后放弃了，没有转化为任何价值

**教训**：
- 免费试用也需要做 ICP 筛选。"来者不拒"在种子期是资源的浪费
- 接触前 5 分钟问 5 个 ICP 筛查问题（见第七节），不合格的礼貌拒绝（"我们的工具目前主要面向规模较大的化学组，可能不太适合贵校的情况"）
- 拒绝不是失礼，为不适合的客户节省时间也是价值

## 十二、理想的二层和三层 ICP（扩展池）

### 二层 ICP（省内扩年级/扩城市层级）

当一层 ICP（湖南地级市重点高中高三化学组）验证成功后：

| 层 | 画像 | 扩展条件 | 差异化策略 |
|----|------|---------|-----------|
| **二层 A** | 湖南省内地级市重点高中高一/高二化学组（扩年级） | 高三成功后，高一高二自然跟随（新高三 = 今年的高二） | 高一高二的考试频次低 -> 需要补充"随堂测验""课后作业"等日常诊断场景 |
| **二层 B** | 湖南省会城市长沙的重点高中（扩城市层级） | 地级市案例积累 >= 5 个后 | 长沙市场竞争更激烈（竞品多）-> 需要更系统的品牌建设；长沙大学的附属中学（如省属师范大学附属中学等）是"标杆中的标杆" |
| **二层 C** | 湖南普通高中（扩学校类型） | 重点高中案例 >= 10 个后 | 普通高中预算更低 -> 需要更低价的方案（如 2000-3000 元/班/年）；普通高中教师的技术水平需要更多的培训支持 |

### 三层 ICP（跨省扩展）

当湖南省内 >= 20 所学校后：

| 层 | 画像 | 扩展条件 | 进入策略 |
|----|------|---------|---------|
| **三层 A** | 湖北省地级市重点高中 | 湖南 >= 20 所学校 | 湖北与湖南高考模式相同（3+1+2），市场结构和竞争强度相似。通过湖南省化学年会的跨省推荐切入 |
| **三层 B** | 山东省地级市重点高中 | 湖南+湖北 >= 30 所 | 山东是全国高考最大省份之一（考生 ~80 万），化学竞争激烈。进入需要省级教研会议或已有客户的跨省推荐 |
| **三层 C** | 江苏省地级市重点高中 | 湖南+湖北 >= 30 所 | 江苏教育信息化水平高、预算充足，但竞争也更激烈。需要积累更多案例后进入 |

## 十三、ICP 对 GTM 决策的指导

| GTM 决策 | ICP 指导 | 具体执行 |
|---------|---------|---------|
| **营销信息** | "你们学校化学组的月考分析还靠画'正'字吗？" -- 直接戳中高三备课组长的统计痛点 | 所有营销材料以"考后统计耗时"为钩子，以"15 分钟出报告"为承诺 |
| **案例素材** | 第一份 Case Study 应该是"湖南某地级市重点高中高三化学组使用 ChemAI 后，月考分析时间从 8 小时降到 1 小时" | 优先积累备课组长A（案例 1）这样的 Tier 1 ICP 案例 |
| **渠道选择** | 省级化学教研会议（备课组长会参加）> 教育信息化展会（信息中心主任会参加） | 2026.Q4-2027.Q1 至少参加 1 次省级化学年会 |
| **定价策略** | 以"年费/班"为计价单位（备课组长理解的是"班"而不是"学生数"），定价在 3000-8000 元区间（地级市重点高中可承受） | 种子学校享受折扣（2000-3000 元/班），推广期恢复标准定价 |
| **销售话术** | 从"我们有很多功能"转变为"我们解决了高三备课组长最头疼的一个问题 -- 月考后的分析时间" | 所有销售触点（demo/官网/文档）围绕"一个核心痛点"展开 |
| **客户成功** | 优先服务 Tier 1 ICP 学校（他们是最重要的案例和转介绍来源） | Tier 1 学校每两周 1 次回访；Tier 2 每月 1 次；Tier 3 被动响应 |
| **转介绍机制** | 备课组长的社交圈是高度同质化的（都是同类的备课组长），转介绍是最高效的获客方式 | 每签约 1 所 Tier 1 学校，请求介绍 2-3 位同行的备课组长 |

### 14.2 ICP 定义是否需要调整的信号

如果在种子期发现以下信号，需要重新审视 ICP 定义：

| 信号 | 可能的调整方向 |
|------|-------------|
| 高三备课组长周活 >= 80% 但高一高二的也有 70%+ | 扩展 ICP 到高一高二 |
| 普通高中的使用频率和满意度与重点高中无显著差异 | 扩展 ICP 到普通高中 |
| 省会（长沙）学校的采购意愿明显高于地级市 | 调整 ICP 地理位置权重（省会优先） |
| 教龄 < 5 年的备课组长比 8-15 年的更活跃 | 调整 ICP 教龄范围 |
| 没有学科网会员的学校也愿意付费（因为痛点够痛） | 放宽"现有工具使用"的 ICP 条件 |
| 化学选考率 < 40% 的学校也有强需求 | 降低"化学选考率"的 ICP 门槛 |

### 14.3 ICP 采购决策驱动因素权重调研

以下是在种子期应向种子学校的关键决策者了解的实际决策权重（假设数据，种子期需验证）：

| 决策因素 | 备课组长权重 | 教研主任权重 | 校长权重 | ChemAI应对 |
|---------|------------|------------|---------|-----------|
| 价格合理性 | 20% | 25% | 35% | 按班计价的低门槛切入 |
| 功能匹配度 | 40% | 30% | 15% | 聚焦"考后统计耗时"这一个核心痛点 |
| 品牌/口碑 | 10% | 15% | 25% | 通过案例和教研会议补品牌缺失 |
| 使用便利性 | 20% | 10% | 5% | 5分钟上手+手把手onboarding |
| 数据安全 | 5% | 10% | 15% | 合规白皮书+安全审核报告 |
| 同行推荐 | 5% | 10% | 5% | 种子老师的转介绍网络 |
