**七态状态机转换图**：

```
                    ┌──────────┐
                    │  CANCELLED │  ← 终态（从draft/published/in_progress均可取消）
                    └──────────┘
                         ▲
                         │
    draft ──→ published ──→ in_progress ──→ grading ──→ completed ──→ archived
                                                              ▲
                                                              └── 终态
```

**关键守卫条件**：
- draft -> published：必须包含至少1道题目，且start_time和end_time已设置
- published -> in_progress：start_time必须已到
- 已完成状态不可取消、不可删除
- 终态(archived/cancelled)不可再转换

**验证**：

```bash
cd backend && python -m pytest tests/test_exam_state_machine.py -v
```

预期：13条测试全部通过。

**如果出错**：

| 错误 | 原因 | 解决 |
|------|------|------|

| 错误 | 原因 | 解决 |
|------|------|------|
| ChromaDB 启动失败：`chromadb.errors.ChromaError` 或 `Permission denied` | 持久化路径无写入权限 | 检查 `CHROMA_PERSIST_DIR` 配置路径，确保目录存在且可写：`mkdir -p ./chroma_db && chmod 755 ./chroma_db` |
| `POST /api/vector-search/rebuild` 后搜索仍返回空 | embedding 模型未正确加载或题目未入库 | 确认 `paraphrase-multilingual-MiniLM-L12-v2` 模型已下载（检查 `~/.cache/huggingface/`），执行 rebuild 后检查返回的 `indexed_count` |
| embedding 模型下载超时或 403 | HuggingFace 被墙或网络不稳定 | 设置环境变量 `HF_ENDPOINT=https://hf-mirror.com`，或手动下载模型到本地目录后用 `SentenceTransformer("本地路径")` 加载 |
| PDF 中文显示为方框（□□□） | ReportLab 未注册中文字体 | Windows: `pdfmetrics.registerFont(TTFont('SimSun', 'C:/Windows/Fonts/simsun.ttc'))`；Linux: 安装 `fonts-wqy-microhei` 后注册 |
| PDF 生成后页面空白 | 字段占位符与实际数据 key 不匹配 | 检查 `paper_exporter.py` 中 `drawString()` 和模板变量名的对应关系 |
| DOCX 表格列宽不对齐、内容溢出 | python-docx 未显式设置列宽 | 设置 `table.autofit = True` 并为每列调用 `cell.width = Cm(具体值)` |
| DOCX 中化学方程式下标未格式化（如 H2O 而非 H₂O） | 导出时未做富文本处理 | 在 DOCX 导出中对化学式数字添加 subscript run 处理 |
| `curl` 导出 PDF 返回 500 | 导出服务依赖的字体文件缺失或题目数据异常 | 查看 FastAPI 后端日志定位具体异常堆栈 |
| 相似题搜索结果包含自身 | `exclude_id` 参数未传入或过滤逻辑遗漏 | 检查向量搜索 API 调用时传入 `exclude_ids=[question_id]` 参数并在结果中过滤 |

## 四、错误处理速查表

| 错误现象 | 根因 | 解决 |
|---------|------|------|
| `/api/questions` 返回404 | 路由未注册 | `main.py`中`include_router(questions.router)` |
| 创建题目返回422 | Schema字段类型不匹配 | 检查JSON字段名和类型与Pydantic一致 |
| 状态转换返回400 | 守卫条件不满足 | 检查exam是否有题目、时间是否设置 |
| 向量搜索返回空 | 索引未构建 | 先调用`POST /api/vector-search/rebuild` |
| PDF中文显示方框 | 中文字体未加载 | Windows用`C:/Windows/Fonts/simsun.ttc`注册ReportLab字体 |
| sentence-transformers下载慢 | 网络问题 | 设`HF_ENDPOINT=https://hf-mirror.com` |
| ChromaDB搜索慢 | 索引数据量大 | 确认已安装`duckdb`，或限制metadata过滤 |
| 前端CSV导入中文乱码 | Excel默认ANSI编码 | 提示用户用UTF-8保存，或前端检测BOM |
| DOCX表格错乱 | python-docx列宽未设置 | 设表格`autofit=True` + 显式列宽 |
| 考试列表不刷新 | 状态转换后未重新fetch | transition成功后调用`fetchExams()` |
