### Step 1: /opsx:propose "实现自适应练习与间隔复习：ZPD模型动态出题 + 障碍→策略矩阵 + 艾宾浩斯5级ReviewTask状态机 + 错题变式题生成与强化训练"

**操作**（在Claude Code中输入）：

```
/opsx:propose "实现自适应练习与间隔复习系统。核心需求：
1. ZPD难度计算：基于学生最近30条答题记录正确率，映射到easy/medium/hard三档（<40%→easy, 40-70%→medium, >70%→hard）
2. 自适应策略矩阵：根据主导障碍类型(concept/reading/expression)决定出题策略——concept降一级难度+基础知识点题，reading保持难度+陷阱题，expression保持难度+计算题
3. 个性化出题参数组装：薄弱知识点优先+ZPD难度+策略矩阵，默认10题
4. ReviewTask状态机：pending/overdue/done三态，5级艾宾浩斯螺旋复习(1/3/7/14/30天)，连续2次答对升级、答错降级
5. 错题自动同步：答错后自动创建ReviewTask，去重幂等
6. 变式题生成器：4维度(数值/物质/选项/题干)生成3道变式题
7. 训练会话：创建→作答→分析循环，4级建议(>=90%已掌握, >=70%继续练习, >=50%需努力, <50%先复习)
目标页面：/student/practice, /student/review"
```

**验证**：确认提案中scope标注为practice，tasks拆分为3个阶段（ZPD引擎、ReviewTask状态机、前端组件）。

**你应该看到**：34个测试从全红到全绿。最复杂的测试是test_scenario_zhangsan_redox（完整模拟张三的氧化还原反应错题复习轨迹）。

**验证**：确认升降级时机正确——降级是"答错后立即检查level>0即降"，不是"等连续错误数达标"。确认level 5后next_review_at为None，status自动变为done。确认变式题LLM prompt中包含4个维度的明确要求。

**如果出错**：

| 错误 | 原因 | 解决 |
|------|------|------|
| 升降级时机判断错误 | 降级逻辑在答对判断之前执行 | 确认顺序：先判断is_correct，答对才检查consecutive_correct>=2，答错则检查level>0立即降级 |
| 场景推演测试中断链 | 某步的状态变更与预期不符 | 逐条核对consecutive_correct和consecutive_errors在每一步后的值 |
| 变式题内容重复 | LLM mock返回的预设数据不够多样 | mock中预设3道内容完全不同的变式题 |
