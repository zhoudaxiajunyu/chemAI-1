**中间件常见错误速查**：

| 错误 | 原因 | 解决 |
|------|------|------|
| `KeyError: 'SECRET_KEY'` | config.py不存在或导入路径错误 | 确认 `app/utils/config.py` 已创建并在middleware中正确导入 |
| `assert 401 == 403` | 白名单路径未生效 | 检查路径匹配逻辑使用 `.startswith()` 而非 `==` |
| `TestClient返回500` | Authorization header为None时未处理 | 在middleware中添加try-except，非白名单且无token时返回401 |
| `ImportError: cannot import name 'verify_jwt'` | jwt.py中函数名不一致 | 确认函数名为 `verify_jwt` |
| `ModuleNotFoundError: No module named 'app.middleware.auth'` | 目录或文件不存在 | 确认 `app/middleware/` 包含 `__init__.py` 和 `auth.py` |

**如果出错（JWT+权限综合）**：

| 错误 | 原因 | 解决 |
|------|------|------|
| `JWTError` 或 `JWSSignatureError` | python-jose 验签失败（篡改、密钥错误或格式非法） | 确认 create_jwt/verify_jwt 使用相同 secret 且 algorithms=["HS256"]；篡改测试中改动 token 任意字符后应抛 JWTError |
| 有效 token 被误判为过期 | 测试环境的 exp 计算与真实时间偏差（如 mock 时间未同步） | 确认 create_jwt 的 exp 用 `datetime.now(timezone.utc)` 计算；freezegun/mock 时间与生成 token 时一致 |
| `ROLE_PERMISSIONS` 矩阵导入路径错误（`ImportError: cannot import name 'ROLE_PERMISSIONS'`） | `permissions.py` 中变量名或导出路径与中间件中 import 路径不一致 | 确认 `app/utils/permissions.py` 中变量名为 `ROLE_PERMISSIONS`；中间件中 import 路径为 `from app.utils.permissions import ROLE_PERMISSIONS, check_permission` ；运行 `python -c "from app.utils.permissions import ROLE_PERMISSIONS; print(list(ROLE_PERMISSIONS.keys()))"` 快速验证 |
| 中间件未正确拦截未认证请求（白名单外的路径无 token 仍返回 200） | 白名单匹配逻辑过于宽泛（如 `/api/` 匹配了所有 API 路径） | 将白名单改为精确前缀列表：仅 `/api/auth/`、`/api/agent/`、`/api/ocr/` 三个具体路径而非 `/api/`；用 TestClient 逐路径测试确认 |
