**apply 过程中常见错误速查**：

| 错误 | 原因 | 解决 |
|------|------|------|
| `ImportError: cannot import name 'SQLAlchemy'` | SQLAlchemy 未安装或版本不兼容 | `pip install sqlalchemy>=2.0` |
| `sqlalchemy.exc.OperationalError: unable to open database file` | `DATABASE_URL` 环境变量未设置或路径无写入权限 | 检查 `.env` 文件中 `DATABASE_URL` 配置，确保当前目录可写 |
| API路由返回 404 | 路由未注册或 prefix 配置错误 | 检查 `main.py` 中的 `include_router` 注册是否正确 |
| 创建资源返回 422 | Schema 与请求体不匹配 | 核对 Pydantic schema 字段定义，确保请求 JSON key 与字段名一致 |
| `no such table` | 数据库迁移未执行 | 执行 `alembic upgrade head` 或在启动时调用 `Base.metadata.create_all()` |
| pytest 报 `ModuleNotFoundError: No module named 'app'` | 测试运行目录不正确 | `cd backend` 后再执行 pytest，或配置 `pythonpath` |
| 合法转换被错误拦截 | 守卫条件有误 | 对照设计文档检查守卫函数中的条件逻辑 |
| 非法转换未被拦截 | 状态转换规则遗漏了该路径 | 对照设计文档补充缺失的禁止规则 |
| 向量数据库启动失败 | 持久化路径无写入权限 | 检查配置的持久化目录路径，确保目录存在且可写 |
| PDF 中文显示为方框 | 中文字体未注册 | Windows 注册 SimSun；Linux 安装文泉驿字体后注册 |
| DOCX 化学方程式格式错误 | 导出时未做富文本处理 | 对化学式中的数字做 subscript 处理 |
