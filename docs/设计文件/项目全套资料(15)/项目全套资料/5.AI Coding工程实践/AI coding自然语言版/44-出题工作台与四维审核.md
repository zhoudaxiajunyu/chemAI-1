## 技术栈说明

教师端前端为 **Vite + React 19 组件化 SPA**（设计文档 37 正式选型；学生端/家长端为移动优先轻量页面，不引入框架构建步骤）：

| 技术 | 版本 | 用途 |
|------|------|------|
| React（react / react-dom） | ^19 | 教师端组件化 SPA：Tab 切换、表单、列表渲染 |
| antd | ^6 | 基础组件库（表格、抽屉、弹窗、表单、消息） |
| vite | ^8.0.14 | 构建工具、HMR、API proxy（`/api` → `localhost:8000`） |
| tailwindcss | ^4 | 原子化样式，与 antd 组件协同 |
| katex | ^0.17.0 | 化学公式/方程渲染（KaTeX + mhchem） |
| marked | ^18.0.5 | Markdown 题干解析 |

**注意**：使用 Vite dev server（`npm run dev`，默认 5173 端口，`/api` 代理到 `localhost:8000`）。不要用 CDN 直挂 Vue/Vanilla 方案实现教师端页面。本阶段不引入 TypeScript 类型定义与 Vitest 配置，保持轻量。组件文件放 `frontend/pages/` 对应 Vite 多页面入口，页面视觉遵守项目根目录的 DESIGN.md（42号文档创建的前端视觉规范）。
